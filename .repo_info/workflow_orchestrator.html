class WorkflowOrchestrator

Central workflow orchestrator. Initialises all spectro agents via RuntimeContainer, builds a LangGraph StateGraph with conditional routing, and exposes run_analysis_single with retry logic. The SelfEvolve node is wired but conditionally skipped unless ground truth is available.

_create_workflow

_create_workflow(self) -> StateGraph

Build and compile the LangGraph StateGraph. Registers 7 nodes, sets the entry point to visual_interpreter, adds a conditional edge for early exit (no features → placeholder report → END), and wires the sequential pipeline: VI → HA search → Feature Auditor → HA synthesis → Analysis Auditor → Report Writer → END.

run_analysis_single

async run_analysis_single(self, state: SpectroState, cancel_checker=None) -> SpectroState

Execute the full analysis pipeline with retry logic. Stores a cancel checker for cooperative cancellation, deep-copies the initial state for clean retry on connection/timeout errors, runs the compiled workflow via ainvoke. On connection or timeout errors, waits retry_delay seconds and restarts from the clean initial state. Non-retryable errors are raised immediately.

Pipeline Topology

The compiled StateGraph topology. The no_features early-exit path bypasses all downstream agents when CWT finds zero features.

Stage 1 Visual Interpreter

FITS loading → CWT feature detection → continuum fitting → redshift hypotheses (brute-force or Redrock). Sets _no_features flag if zero peaks and zero troughs detected.

↓
Conditional _has_features

If _no_features → early exit: writes placeholder report + JSON via _no_features_node, then terminates. Otherwise → continues to Stage 2.

↓
Stage 2 HA — Single-Hypothesis Search

Collects redshift hypotheses from VI, runs first serially (KV-cache warm), then remainder concurrently (Semaphore). Saves per-hypothesis CSVs and diagnostic plots.

↓
Stage 3 Feature Auditor

Builds cross-hypothesis contradiction matrix. LLM verifies each feature against the raw spectrum (read_spectrum_region) and votes is_real/is_noise/is_uncertain. Detects doublet morphology. Writes cleaned CSVs with per-feature verdicts.

↓
Stage 4 HA — Synthesis

Cross-hypothesis comparison. Builds Dn4000 diagnostic slices, formats structured summaries from CSV line data, runs LLM synthesis with the verified feature matrix. Produces a synthesis verdict (CONFIRM/REJECT/UNCERTAIN).

↓
Stage 5 Analysis Auditor

Adversarial second review of the synthesis conclusion. Builds CWT catalog for all-feature querying, runs independent LLM audit with query_cwt_catalog tool. Outputs calibrated confidence (HIGH/MEDIUM/LOW) and revision suggestions.

↓
Stage 6 Report Writer

Generates structured 6-section Markdown report: classification, redshift, confidence, line evidence, uncertainties, recommendations. Writes to disk via ResultWriter.

Error resilience: On connection or timeout errors, run_analysis_single deep-copies the original SpectroState and restarts the entire pipeline from scratch — preventing dirty intermediate state (especially List-append fields) from corrupting the retry. Non-retryable errors (auth failure, invalid request) are raised immediately.
