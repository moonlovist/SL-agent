create_client

create_client(self) -> ChatOpenAI

Build the ChatOpenAI client from stored config:

thinking modes:
'none' — skip thinking params entirely (for models like qwen-vl-max that don't support them)
'disabled' — explicitly disable; base_agent may later bind-override to 'enabled' when want_tools=False
'enabled' — enable thinking; base_agent will bind-override to 'disabled' when want_tools=True (preserving multi-turn tool-call safety)

OutputTypeDescription
clientChatOpenAIConfigured ChatOpenAI instance, ready for LangChain agent binding. Reads all params from self.model_config; delegates to _create_chat_openai.
Why the DeepSeek patch? langchain-openai rewrites max_tokens to max_completion_tokens on every request. DeepSeek's API ignores the renamed field and uses its own default (8192). Without this patch, max_tokens configuration is silently dropped for all DeepSeek calls — the agent may appear to work but produces truncated or unexpectedly short completions.
