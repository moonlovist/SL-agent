validate_by_mode

@model_validator(mode='after') validate_by_mode(self) -> IOConfig

Cross-field validation executed after all fields are populated. Checks that input_dir, output_dir, run_mode are non-empty; run_mode is 's' or 'b'; and file_name is set when run_mode='s'.
