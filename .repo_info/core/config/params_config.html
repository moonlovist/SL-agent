from_env

@classmethod from_env() -> ParamsConfig

Construct from 24 environment variables across core, Redrock, and CWT groups. Validates ARM_NAME/ARM_WAVELENGTH_RANGE consistency (both set → equal length). Boolean flags parsed via .lower() in ("true","1","yes"). Numeric fields use getenv_int/getenv_float helpers.

OutputTypeDescription
configParamsConfigNew validated instance with all 24 fields populated

_parse_arm_name

OutputTypeDescription

_parse_arm_wavelength_range

@staticmethod _parse_arm_wavelength_range() -> Optional[List[List[float]]]

Parse ARM_WAVELENGTH_RANGE env var. Format: "3600-5800,5760-7620,7520-9824" → split by comma then -, validate 2 parts per range, parse as float. Returns None if empty or missing; raises ValueError on malformed input.

OutputTypeDescription
rangesOptional[List[List[float]]]e.g. [[3600.0,5800.0],[5760.0,7620.0],[7520.0,9824.0]], or None
