safe_to_bool

safe_to_bool(value: Optional[str]) -> bool

Coerce a value to boolean safely. If already bool, pass through. If str, match against {"true","1","t","yes","y"} (case-insensitive). All other values (including None) return False.

ParameterTypeDefaultDescription
valueOptional[str]—Value to coerce; bool passes through, str is matched
OutputTypeDescription
resultboolTrue only for recognised truthy strings or existing True

getenv_int

getenv_int(name: str, default: int) -> int

Read an environment variable and parse as int. On parse failure, prints a warning and returns default. On missing/empty env var, returns default.

ParameterTypeDefaultDescription
namestr—Environment variable name
defaultint—Fallback value when env var is missing or unparseable
OutputTypeDescription
valueintParsed integer or default

getenv_float(name: str, default: float) -> float

getenv_optional_float

getenv_optional_float(name: str) -> Optional[float]

Read an environment variable and parse as float. Returns None (instead of a default) on parse failure or missing value. Used for optional numeric params where None has semantic meaning distinct from a fallback.

ParameterTypeDefaultDescription
namestr—Environment variable name
OutputTypeDescription
valueOptional[float]Parsed float, or None if missing or unparseable

getenv_int_list

getenv_int_list(name: str, default: List[int]) -> List[int]

Read a comma-separated environment variable and parse as a list of int. On parse failure, prints a warning and returns default.

ParameterTypeDefaultDescription
namestr—Environment variable name
defaultList[int]—Fallback list when env var is missing or unparseable
OutputTypeDescription
valuesList[int]Parsed integer list or default
Why a separate utils module? The env-var parsing logic is shared across ModelConfig, ParamsConfig, and potentially other config models. Extracting these helpers avoids code duplication and centralizes error-handling conventions (warn on parse failure, return default).
