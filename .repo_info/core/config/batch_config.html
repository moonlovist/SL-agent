parse_batch_range

parse_batch_range(start: str, end: str) -> List[str]

Module-level helper. Converts a numeric string range into a list of string IDs. Detects zero-padding: ("001","005") → ["001","002","003","004","005"], ("1","5") → ["1","2","3","4","5"].

ParameterTypeDefaultDescription
startstr—Start of numeric range (must be digits)
endstr—End of numeric range (must be digits, ≥ start)
OutputTypeDescription
idsList[str]Ordered list of numeric ID strings, zero-padded if the input was

class BatchConfig

Pydantic model with three fields. Agents use this config to determine whether the system is in single-file or batch mode — if both start and end are set, generate_ids() produces the full file ID list.

KeyTypeEnv VarDescription
headerstrFILE_BATCH_HEADERoptional prefix for generated file IDs (default "")
startOptional[str]FILE_BATCH_STARTstart of numeric index range, validated as digits
endOptional[str]FILE_BATCH_ENDend of numeric index range, validated as digits

from_env

@classmethod from_env() -> BatchConfig

Construct from environment variables: FILE_BATCH_HEADER (default ""), FILE_BATCH_START, FILE_BATCH_END. If start/end are not set, they remain None, putting the system in single-file mode.

OutputTypeDescription
configBatchConfigNew instance with fields populated from env vars

validate_digit

@field_validator("start", "end") validate_digit(v) -> Optional[str]

Pydantic field validator. If v is None, passes through. Otherwise asserts v.isdigit() — raises ValueError on non-numeric batch start/end values.

ParameterTypeDefaultDescription
vOptional[str]—Field value being validated (may be None)
OutputTypeDescription
vOptional[str]Validated value, or None if input was None

is_batch_mode

is_batch_mode(self) -> bool

Returns True only when both start and end are non-None. Controls whether the system generates a file ID list or uses the single FILE_NAME from IOConfig.

OutputTypeDescription
in_batchboolTrue if both start and end are set, False otherwise

generate_ids

generate_ids(self) -> List[str]

If batch mode is active, calls parse_batch_range(start, end) and prefixes each index with self.header (e.g. ["spec-001", "spec-002", ...]). Returns empty list if not in batch mode.

OutputTypeDescription
idsList[str]Ordered file ID list with header prefix, or [] if not batch mode
