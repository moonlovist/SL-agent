class RuntimeContainer

Dependency injection container. Holds a reference to the full AllConfig and a private model cache (_models: dict). Agents receive this container at construction time and call get_model() to obtain their LLM/VLM client.

__init__

__init__(self, configs: AllConfig)

Store the config object and initialize an empty _models dict. No clients are created eagerly — all model construction is deferred to the first get_model() call.

get_model

get_model(self, type: str) -> ChatOpenAI

Lazy-initialize and cache a model client by type key. Looks up configs.model.type, passes the config dict to ThisIsModel(config).create_client(), and caches the result in _models[type].

ParameterTypeDefaultDescription
typestr—Model type key, e.g. "llm" or "vlm", indexing into configs.model
OutputTypeDescription
clientChatOpenAIReady-to-use ChatOpenAI instance, cached per type key for reuse
Why lazy init? Different agents may request different model types (e.g. "llm" for text-only agents, "vlm" for vision agents). By deferring construction to the first get_model() call, models that are never requested are never built — saving API key validation and connection setup for unused backends.
