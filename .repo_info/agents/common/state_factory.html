class StateFactory

Factory that builds initial SpectroState instances. Takes an AllConfig at construction; the create() method resolves input/output paths and returns a ready-to-use state object.

create

create(self, file_name: str, input_dir: str, output_dir: str) -> SpectroState

Build a new SpectroState. Resolves file_path from input_dir + file_name + input_format, creates per-spectrum output directory with visual_interpreter/ sub-directory, pre-fills image paths and initialises all empty containers (qualitative_analysis, rule_analysis_*, extract_*, auditing_history_*, in_brief, etc.).

ParameterTypeDefaultDescription
file_namestr—Base file name (without extension)
input_dirstr—Directory containing input spectrum files
output_dirstr—Root output directory; per-spectrum sub-directory is created under it
OutputTypeDescription
stateSpectroStateInitialised state ready for the LangGraph pipeline
Why a separate factory? SpectroState construction involves path resolution and directory creation that depend on IOConfig. Keeping this logic in a dedicated factory avoids cluttering the state class and makes it easy to adjust path conventions without touching the state definition. See SpectroState for the full field list.
