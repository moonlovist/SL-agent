image_to_base64

image_to_base64(image_path: str) -> str

Read an image file from disk and encode it as a base64 string. Used to embed images in LangChain HumanMessage content blocks via data:image/jpeg;base64,... URLs.

ParameterTypeDefaultDescription
image_pathstr—Path to the image file on disk
OutputTypeDescription
datastrBase64-encoded image data

create_message

create_message(system_prompt: str, user_prompt: str, image_path: Optional[str] = None) -> list

Build a LangChain message list. Wraps system_prompt in a SystemMessage, creates a HumanMessage with user_prompt as text. If image_path is provided (str or list), appends base64 image_url blocks.

ParameterTypeDefaultDescription
system_promptstr—System prompt text
user_promptstr—User prompt text
image_pathOptional[str]NonePath(s) to image file(s); appends base64 blocks if set
OutputTypeDescription
messageslist[SystemMessage, HumanMessage] ready for model.ainvoke()
Where this is used: BaseAgent.call_llm_with_context() calls create_message(system_prompt, user_prompt, image_path) to assemble the message list before invoking the LLM or VLM. See BaseAgent.
