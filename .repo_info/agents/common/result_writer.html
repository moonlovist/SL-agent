class ResultWriter

Centralised result output manager. Two public write methods — read-only, safe for repeated calls in a processing loop.

write_redshift_hypotheses

write_redshift_hypotheses(self, state: SpectroState) -> None

Write redshift hypotheses to a formatted .txt file. Handles both new dict format (with zmedian, z, hypotheses) and legacy list format. Outputs key fields per hypothesis in a defined order.
