class VisualInterpreter

Inherits: BaseAgent

Stage 1 Agent. Entry point of the FORMA pipeline. Accepts a FITS file path, extracts calibrated spectra per arm, runs CWT feature detection, fits the continuum with feature region masking, and generates ranked redshift hypotheses.

load_spectrum_from_fits

load_spectrum_from_fits(self, state: SpectroState) -> SpectroState

run

async run(self, state: SpectroState, plot: bool = True) -> SpectroState

Main entry point — executes the full Stage 1 pipeline. Checks INPUT_FORMAT from config; if 'fits', runs load_spectrum_from_fits (PNG branch is disabled). Then proceeds through overlap region computation, diagnostic plotting, NPZ persistence, CWT feature detection, continuum fitting with feature masking, and redshift hypothesis generation (brute-force line matching or Redrock pipeline depending on params.redrock).

The pipeline proceeds in these phases:

  • FITS loading — _load_spectrum_from_fits() extracts wavelength, flux, ivar per arm from the FITS file.
  • Overlap / Plot / NPZ — Computes arm overlap regions, generates spec-extract and SNR plots, saves {file_name}_spectrum.npz.
  • CWT feature detection — run_cwt_feature_detection() detects emission and absorption lines; stores state['peaks'], state['troughs'], state['emission_records'], state['absorption_records'].
  • Continuum fitting — run_continuum_fitting_masked() fits a Chebyshev polynomial continuum with detected features masked; stores state['continuum'] and state['residual_spectrum'].
  • Feature plot — plot_features() renders detected emission / absorption lines on the spectrum.
  • Redshift hypotheses — If params.redrock is true, runs run_redrock_pipeline(); otherwise runs brute_force_line_matching(). Stores state['redshift_hypotheses'].
  • Output — ResultWriter.write_redshift_hypotheses(state) persists the hypotheses.
ParameterTypeDefaultDescription
stateSpectroState—Pipeline state with file_path and output_dir populated.
plotboolTrueWhether to generate diagnostic plots (spec-extract, SNR, continuum, residual, features).
OutputTypeDescription
stateSpectroStateState populated with spectrum, peaks/troughs lists, emission/absorption records, continuum/residual arrays, and redshift_hypotheses. Also writes NPZ and plot files to output_dir/visual_interpreter/.

PNG Channel (disabled)

The PNG / VLM input channel was disabled on 2026-06-30 because PaddleOCR and Tesseract dependencies are cumbersome to install. During testing, only FITS input is supported. The following commented-out methods implement the PNG-only processing flow (Phases A through C). To restore, uncomment the corresponding imports and method bodies in VisualInterpreter.py and utils/VI.py.

MethodDescription
* detect_axis_ticksCall VLM (LLM with image) to detect axis tick marks from a spectrum plot image. Returns structured axis_info; raises if image is not a spectrum plot.
* detect_axis_ticks_OCRCall OCR engine (PaddleOCR or Tesseract, selected via params.ocr) to detect tick labels from the image.
* combine_axis_mappingUse LLM to merge VLM and OCR tick results into a single consistent pixel-to-value mapping. Checks monotonicity and resolves conflicts.
* revise_axis_mappingUse LLM to check and correct the combined tick-pixel mapping for monotonicity violations.
* check_borderCall LLM to judge whether cropping has removed all four borders (top, right, bottom, left) cleanly. Returns a dict of boolean flags.
* border_detection_and_croppingIterative cropping loop: _detect_chart_border → _crop_img → check_border. Increases margin by 2px per dirty edge, stops when all edges are clean or margin reaches 30px.

The disabled PNG channel also includes utility functions from utils/VI.py that remain available but unused: _detect_chart_border, _crop_img, _remap_to_cropped_canvas, _pixel_tickvalue_fitting, and _convert_to_spectrum.

Pipeline Steps

The run() method orchestrates the following pipeline. Each step is implemented by dedicated utility functions in utils/; results are written back to SpectroState at the agent layer.

Phase A · Step 1 FITS Loading

Checks INPUT_FORMAT from config. If 'fits', delegates to _load_spectrum_from_fits() which extracts wavelength, flux, ivar, and SNR arrays per arm from the FITS HDU structure. PNG branch raises NotImplementedError (channel disabled). Populates state['spectrum'].

↓
Phase A · Step 2 Overlap, Plot & Persist

Computes arm overlap regions via find_overlap_regions(). Generates spec-extract and SNR diagnostic plots. Saves the full spectrum as {file_name}_spectrum.npz for downstream harness agents.

↓
Phase D · Step 3 CWT Feature Detection

Calls run_cwt_feature_detection() — Ricker wavelet transform across configurable scales, ridge-line detection in scale-space, emission/absorption classification. Populates state['peaks'], state['troughs'], state['emission_records'], state['absorption_records']. Optionally renders plot_features() with wavelength annotations.

↓
Phase E · Step 4 Continuum Fitting

Iterative Chebyshev polynomial fit via run_continuum_fitting_masked(). Detected features are masked (centre ± 3σ), degree is auto-selected or config-driven, and outliers are rejected. Stores state['continuum'] and state['residual_spectrum']. Generates continuum and residual plots.

↓
Phase E · Step 5 Redshift Hypothesis Generation

If params.redrock is enabled, runs run_redrock_pipeline() (external template-fitting engine). Otherwise runs brute_force_line_matching() — unified single-pass matching with Union-Find dedup, ranked by N_emission + N_absorption. Results stored in state['redshift_hypotheses'] and persisted via ResultWriter.write_redshift_hypotheses().
