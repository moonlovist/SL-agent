_local_noise_mad

_local_noise_mad(signal, half_window=50) -> ndarray

Sliding-window MAD (Median Absolute Deviation) noise estimate, robust against spectral line features. Computes a per-pixel noise estimate by taking the MAD within a ±half_window sliding window.

ParameterTypeDefaultDescription
signalndarray—1-D input signal (typically flux or residual)
half_windowint50Half-width of sliding window in pixels
OutputTypeDescription
noisendarrayPer-pixel noise estimate, same length as input

_cwt_ridge_detection

_cwt_ridge_detection(signal, wavelength, scales, snr_thresh=5.0, min_ridge_length=2, tol_pix=10) -> (list[dict], list[dict])

Multi-scale ridge line detection in CWT coefficient space. At each scale, detects local maxima (emission) and minima (absorption) in the wavelet coefficient array, then links them across scales into ridge lines. A ridge must span at least min_ridge_length scales. Ridges within tol_pix pixels across scales are linked.

ParameterTypeDefaultDescription
signalndarray—1-D input signal (continuum-subtracted flux)
wavelengthndarray—Wavelength grid
scalesndarray—CWT scale array (controls feature width sensitivity)
snr_threshfloat5.0SNR threshold for ridge detection at each scale
min_ridge_lengthint2Minimum number of scales a ridge must span
tol_pixint10Pixel tolerance for linking ridges across adjacent scales
OutputTypeDescription
(peaks, troughs)(list[dict], list[dict])Detected ridge features with wavelength, scale_range, snr, amplitude

Public API

find_features_cwt

find_features_cwt(wavelength, flux, snr_thresh=5.0, min_ridge_length=2, n_scales=24, min_scale=1.0, max_scale=80.0, verbose=True) -> (DataFrame, DataFrame)

Main entry point for CWT feature detection. Computes the Ricker wavelet transform across n_scales scales, detects ridge lines in scale-space, classifies them as emission (positive CWT coefficients) or absorption (negative), estimates local noise via MAD, and returns DataFrames with wavelength, amplitude, SNR, and scale range for each detected feature.

ParameterTypeDefaultDescription
wavelengthndarray—Wavelength grid
fluxndarray—Flux values (typically continuum-subtracted)
snr_threshfloat5.0SNR threshold for ridge detection
min_ridge_lengthint2Minimum ridge length in scale steps
n_scalesint24Number of CWT scales (log-spaced)
min_scalefloat1.0Minimum CWT scale in pixels
max_scalefloat80.0Maximum CWT scale in pixels
verboseboolTruePrint detection summary statistics
OutputTypeDescription
(peaks_df, troughs_df)(DataFrame, DataFrame)Detected emission peaks and absorption troughs with wavelength, amplitude, SNR, scale_range

run_cwt_feature_detection

run_cwt_feature_detection(output_dir, file_name, wavelength, flux, ivar=None, effective_snr=None, ...) -> (DataFrame, DataFrame)

High-level runner. Computes continuum-subtracted residual, calls find_features_cwt, saves results as CSV ({file_name}_cwt_peaks.csv, {file_name}_cwt_troughs.csv), and returns the feature DataFrames.

OutputTypeDescription
