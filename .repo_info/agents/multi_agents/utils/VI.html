Line Matching & Redshift Scoring

brute_force_line_matching

brute_force_line_matching(state: SpectroState, tol_wavelength=None) -> SpectroState

Unified single-pass brute-force line matching. Uses all detected CWT peaks and troughs as anchors, computes a redshift for each, matches all emission and absorption lines within tolerance. Applies Union-Find dedup and ranks by N_emission + N_absorption. Stores results in state["redshift_hypotheses"].

ParameterTypeDefaultDescription
stateSpectroState—Workflow state with detected CWT features
tol_wavelengthint | NoneNoneMatching tolerance in Å; falls back to params_config.tol_wavelength
OutputTypeDescription
stateSpectroStateState with redshift_hypotheses populated

run_redshift_scoring_v3

run_redshift_scoring_v3(wavelength, flux, continuum_flux, snr, features_df, redshift_hypotheses, ...) -> dict

Score redshift hypotheses by cross-matching predicted line positions against CWT-detected features. Uses Δχ²-like scoring with Gaussian fitting and iterative outlier rejection. Produces ranked low-z and high-z candidate lists. Current scoring version.

OutputTypeDescription
scoringdictRanked results with low_z, high_z candidate lists and per-line diagnostics
