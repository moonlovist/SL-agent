Utilsplot.py

Path: src/FORMA/agents/multi_agents/utils/plot.py

Visualization utilities. Reads SpectroState and produces diagnostic plots (spectrum, SNR, continuum, residual, masked, features, harness candidates) as PNG files to the output directory. All functions write to disk via matplotlib; none return values.

Internal Helper

_get_figsize

_get_figsize(state: SpectroState) -> tuple[float, float]

Compute the matplotlib figure size from the spectral wavelength range. Wider spectra get wider figures, ensuring consistent aspect ratio across all plots.

ParameterTypeDefaultDescription
stateSpectroState—Workflow state with wavelength data
OutputTypeDescription
(w, h)(float, float)Figure width and height in inches

Spectrum Overview Plots

plot_spectrum_snr

plot_spectrum_snr(state: SpectroState) -> None

Full spectrum overview with SNR overlay. Plots flux and inverse-variance-weighted SNR in two stacked panels. Saves to {file_name}_spectrum_snr.png.

ParameterTypeDefaultDescription
stateSpectroState—Workflow state with wavelength, flux, ivar

plot_spec_extract

plot_spec_extract(state: SpectroState) -> None

Raw spectrum extraction visualisation. Plots the reconstructed multi-band spectrum with arm boundaries marked. Saves to {file_name}_spec_extract.png.

ParameterTypeDefaultDescription
stateSpectroState—Workflow state with extracted spectrum data

plot_continuum

plot_continuum(state: SpectroState) -> None

Spectrum with Chebyshev continuum fit overlay. Shows original flux, fitted continuum, and masked/outlier regions. Saves to {file_name}_continuum.png.

ParameterTypeDefaultDescription
stateSpectroState—Workflow state with continuum fit results

plot_residual_spectrum

plot_residual_spectrum(state: SpectroState) -> None

Residual spectrum (flux − continuum). Highlights positive residuals (emission candidates) and negative residuals (absorption candidates) in different colours. Saves to {file_name}_residual.png.

ParameterTypeDefaultDescription
stateSpectroState—Workflow state with continuum and flux

plot_masked_spectrum

plot_masked_spectrum(state: SpectroState) -> None

Continuum-subtracted spectrum with masked feature regions. Shows which pixels were excluded during continuum fitting. Saves to {file_name}_masked.png.

ParameterTypeDefaultDescription
stateSpectroState—Workflow state with mask array

Feature & Candidate Plots

plot_features

plot_features(state: SpectroState, wavelength_label: bool = True) -> None

Main feature visualization. Plots spectrum with detected CWT emission peaks (green markers) and absorption troughs (red markers) annotated with wavelengths. Saves to {file_name}_features.png.

ParameterTypeDefaultDescription
stateSpectroState—Workflow state with CWT feature DataFrames
wavelength_labelboolTrueWhether to show wavelength labels on each feature

plot_harness_candidate

plot_harness_candidate(state: SpectroState, candidate_index: int, ...) -> None

Plot a single harness candidate hypothesis. Overlays predicted line positions (computed from the candidate redshift) on the observed spectrum, colour-coded by line status (LIKELY/MARGINAL/NOT_FOUND). Used by hypothesis evaluation agents for visual inspection.

ParameterTypeDefaultDescription
stateSpectroState—Workflow state with spectrum data
candidate_indexint—Index into the harness candidate list
