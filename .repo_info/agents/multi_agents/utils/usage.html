safe_to_bool

safe_to_bool(value) -> bool

Safe boolean coercion. bool passes through; str matches ['true','1','t','yes','y'] (case-insensitive); all other values fall through to bool(value).

ParameterTypeDefaultDescription
valueAny—Value to coerce to boolean
OutputTypeDescription
resultboolCoerced boolean value

find_overlap_regions

find_overlap_regions(band_names, band_wavelengths) -> dict

Find all pairwise overlap regions between spectral bands. Iterates all band pairs (i, j), computes max(start_i, start_j) → min(end_i, end_j).

ParameterTypeDefaultDescription
band_nameslist[str]—Band name labels (e.g. ["B","R","Z"])
band_wavelengthslist[[float,float]]—Wavelength range per band as [start, end]
OutputTypeDescription
overlapsdicte.g. {"B-R": [5760.0, 5800.0], ...}

normalize_line_name

normalize_line_name(raw: str) -> str

Normalise a spectral line name to canonical form. Handles common LLM-generated variants via regex bracket normalisation + alias lookup table (~40 entries covering emission and absorption lines).

ParameterTypeDefaultDescription
rawstr—Raw line name string from LLM output
OutputTypeDescription
namestrCanonical name (e.g. "[O II] 3727") or cleaned input if unmapped
