analyze_failure

async analyze_failure(synthesis_result, harness_results, harness_dir, ground_truth, mismatch_info, *, model, api_key, base_url, wl=None, fl=None, temperature=0.0, stream_md_path=None) -> dict

Call an LLM to identify the root cause of a single synthesis failure. Builds Dn4000 diagnostic slices from the spectrum, formats each harness result into a structured summary, then presents the full context to the LLM with the blind-review skill prompt.

ParameterTypeDefaultDescription
synthesis_resultdict—Full rule_analysis dict from synthesis
harness_resultslist—Raw harness results (used to build summaries the synthesis saw)
harness_dirstr—Directory with harness reports and per-line CSVs
ground_truthdict—{"z": float, "type": str}
mismatch_infodict—{"z_mismatch": bool, "type_mismatch": bool}
modelstr—LLM model name
api_keystr—API key for LLM
base_urlstr—API base URL
wlndarray | NoneNoneWavelength grid; flat placeholder used if None
flndarray | NoneNoneFlux array; flat placeholder used if None
temperaturefloat0.0LLM temperature
stream_md_pathstr | NoneNonePath to stream LLM output; uses default under harness_dir if None
OutputTypeDescription
analysisdict{"root_cause": str, "explanation": str, "suggested_fix": str}

analyze_failure_batch

async analyze_failure_batch(output_dir, batch_num, *, model, api_key, base_url, temperature=0.0) -> dict | None

Run a collective LLM analysis on a batch of pending failures. Reads from failure/pending.jsonl, builds compact failure summaries, streams the LLM response to a Markdown file, and clears the pending queue on success. Uses the batch analysis skill prompt for systematic weakness identification.

ParameterTypeDefaultDescription
output_dirstr—Root output directory
batch_numint—Batch index for naming the output stream file
modelstr—LLM model name
api_keystr—API key
base_urlstr—API base URL
temperaturefloat0.0LLM temperature
OutputTypeDescription
analysisdict | NoneParsed batch analysis dict, or None if no pending failures or LLM fails

_record_failure

_record_failure(synthesis_result, harness_dir, ground_truth, mismatch_info, analysis, output_dir="") -> str

Write a structured failure record with three outputs: (1) per-sample JSON in harness_dir, (2) appended to the pending queue for batch accumulation, (3) appended to the global failure_log.jsonl archive. Extracts the synthesis verdict summary for comparison against ground truth.

ParameterTypeDefaultDescription
synthesis_resultdict—Full rule_analysis dict from synthesis
harness_dirstr—Directory with harness outputs
ground_truthdict—{"z": float, "type": str}
mismatch_infodict—Discrepancy flags from comparison
analysisdict—Root cause analysis from analyze_failure
output_dirstr""Root output directory; defaults to harness_dir
OutputTypeDescription
pending_pathstrPath to the updated pending.jsonl

_write_batch_report

_write_batch_report(output_dir: str, records: list, batch_num: int, analysis: dict) -> str

Generate a comprehensive batch failure analysis report in Markdown. Includes per-failure summaries with ground truth vs prediction comparison, root cause categories, and the collective LLM analysis. Saves to failure/batch_{batch_num}_report.md.

ParameterTypeDefaultDescription
output_dirstr—Root output directory
recordslist[dict]—Accumulated failure records
batch_numint—Batch index for report file naming
analysisdict—Collective analysis from analyze_failure_batch
OutputTypeDescription
pathstrPath to the generated batch report
