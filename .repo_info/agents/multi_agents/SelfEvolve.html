_normalise_spectype

_normalise_spectype(raw: str) -> str

Normalise spectral type strings from FITS metadata for comparison with synthesis classification. Maps short FITS enum values to the long forms used in the pipeline. Unknown or unmapped types are returned unchanged (case-preserved after stripping).

class SelfEvolve

Inherits: BaseAgent

Stage 5 optional agent. Compares synthesis verdict against ground truth via FITS metadata (VI_Z, VI_SPECTYPE) or environment variables (EXPECTED_Z, EXPECTED_TYPE). On mismatch with sufficient confidence and in-scoring redshift, runs a two-round LLM root-cause analysis and writes structured failure records for individual and batch review.

Class variable agent_name = "SelfEvolve" identifies the agent for logging and dispatch.

run

async run(self, state: SpectroState) -> SpectroState

Main entry point. Compares the HypothesisAnalyst synthesis verdict against ground truth and triggers root-cause analysis on mismatch. Returns the state unmodified on pass or skip.

Ground-truth comparison flow:

  • Resolve ground truth — Priority 1: FITS metadata fields VI_Z and VI_SPECTYPE from the spectrum dictionary. Priority 2 (fallback): environment variables EXPECTED_Z and EXPECTED_TYPE. If neither is available, logs an info message and skips.
  • Extract synthesis verdict — Calls extract_verdict_summary(state["hypothesis_analysis"]) to obtain the synthesised redshift, classification, and confidence level.
  • Compute mismatch flags — z_mismatch: True if synthesis z is None or abs(result_z - expected_z) > z_tolerance. type_mismatch: True if summary["classification"] != expected_type.
  • Early-exit conditions — If no mismatch: log PASSED and return. If confidence is "LOW": log abstention and skip. If the true redshift is not in the scoring set (min_dz > tolerance): log and skip (upstream CWT/scoring issue).
  • Run failure analysis — On confirmed mismatch, calls analyze_failure from SE.py which executes a two-round LLM analysis: Round 1 blind review without ground truth, Round 2 root-cause identification with ground truth and tool access (read_spectrum_region, grep_kb).
  • Record failure — Calls _record_failure to write per-sample JSON, append to batch pending queue (failure/pending.jsonl), and append to global log (failure_log.jsonl). Sets state["_failure_recorded"] = True.
ParameterTypeDefaultDescription
stateSpectroState—Pipeline state containing hypothesis_results, hypothesis_analysis, spectrum, and output_dir.
OutputTypeDescription
stateSpectroStateUnmodified state on pass/skip, or state with _failure_recorded = True after failure analysis.

SelfEvolve is optional and controlled by the self_evolve config flag. It distinguishes honest abstention (LOW confidence, no analysis triggered), upstream scoring failures (true z out of scoring range), and genuine synthesis failures that warrant root-cause investigation. The two-round analysis design (blind review first, then ground-truth-informed root cause) reduces confirmation bias in the LLM assessment.
