class ReportWriter

Inherits: BaseAgent

Stage 4 Agent. Final stage of the FORMA pipeline. Called after the Result Auditor. Checks for a valid harness_dir in state, builds LLM kwargs from runtime configuration, and invokes report_writer_arun from the harness to produce a structured 6-section final report. Writes the report to disk as Markdown and extracts a structured JSON comprehensive assessment stored in state['in_brief'].

run

async run(self, state: SpectroState) -> SpectroState

Main entry point — executes the final report writing stage. Checks for a valid harness_dir in state; if missing, sets state['final_report'] and state['in_brief'] to None/{} and returns early. Builds LLM kwargs from the runtime model configuration (model name, api_key, base_url, temperature). Calls report_writer_arun(state, harness_dir, stream_md_path=...) which produces a structured Markdown report and a parsed JSON comprehensive assessment. Stores results in state['final_report'] and state['in_brief'].

OutputTypeDescription
