AgentAnalysisAuditor

Path: src/FORMA/agents/multi_agents/AnalysisAuditor.py

Stage 3 — Two-stage adversarial review (FeatureAuditor + AnalysisAuditor). Stage A performs cross-hypothesis feature verification before synthesis: builds a Feature Contradiction Matrix, then spawns an LLM with spectrum-reading tools to independently verify each claimed feature. Stage B performs an adversarial second review of the synthesis verdict, stress-testing the winning hypothesis by reading the raw spectrum. The largest agent file with 16 module-level functions and 2 classes.

const DOUBLET_DEFS

Module-level constant defining the four canonical astrophysical doublet pairs used by the contradiction matrix builder for cross-hypothesis feature verification. Each entry encodes the expected rest wavelengths, separation, and amplitude ratio check.

DOUBLET_DEFS

DOUBLET_DEFS : list[dict]

Four known doublet pairs:

  • Ca K/H — 3934.8 / 3969.6 A, sep 34.8 A, K deeper than H (K/H > 1)
  • [O III] a/b — 4960.3 / 5008.2 A, sep 47.9 A, b:a approx 3:1
  • [N II] a/b — 6549.8 / 6585.3 A, sep 35.5 A, a:b approx 1:3
  • [S II] a/b — 6718.3 / 6732.7 A, sep 14.4 A, a approx b (ratio ~1.0)

Each entry has name_a, rest_a, name_b, rest_b, sep_rest, ratio_desc, and a check lambda that returns (ratio_ab, is_expected, note).

JSON & Continuation Helpers

Shared utilities for LLM response handling: max-token resolution, smart continuation prompts for truncated responses, JSON extraction from raw text, and recommendation string normalisation.

_resolve_max_tokens

_resolve_max_tokens() -> int | None

Resolve the max_tokens parameter for LLM calls. Reads LLM_MAX_TOKENS env var first; falls back to 65536 for DeepSeek models (detected via LLM_BASE_URL containing "deepseek"); returns None for all other vendors (using LLM default).

ParameterTypeDefaultDescription
none——Reads from environment variables only.
OutputTypeDescription
—int | NoneMax tokens value, or None for default.

_build_continuation_prompt

_build_continuation_prompt(messages: list, json_keys: list[str] | None = None) -> str

Build a smart continuation prompt for the LLM when its previous response was truncated. Analyses the accumulated LangChain messages to determine where the LLM stopped. Uses _find_last_content_ai_message to skip pure tool-call messages and find the last AI message with text output. Behaviour depends on json_keys:

  • ["feature_verdicts"] — FeatureAuditor schema: counts complete wl_obs entries via brace-depth parsing and detects broken entries cut off mid-output.
  • ["verdict"] — ResultAuditor schema: scans already-written top-level keys (verdict, calibrated_confidence, spectrum_quality, key_issues, etc.) and instructs the LLM to continue with remaining fields.
  • Otherwise — generic instruction: do not repeat, output only remaining content.
ParameterTypeDefaultDescription
messageslist—Accumulated LangChain message objects from the streaming session.
json_keyslist[str] | NoneNoneExpected output schema keys for schema-aware continuation behaviour.
OutputTypeDescription
—strContinuation prompt string instructing the LLM where to resume.

_extract_json_block

_extract_json_block(text: str, keys: list[str] | None = None) -> dict | None

Extract a JSON block from an LLM response string. Tries ```json ... ``` fences first, then falls back to scanning for bare {...} blocks that contain any of the specified keys. If keys is None, matches any {...} block at the end of text. Returns the parsed dict, or None if no valid JSON is found.

ParameterTypeDefaultDescription
textstr—Raw LLM response text.
keyslist[str] | NoneNoneKeys that must appear in the JSON block. If None, matches any {...} block.
OutputTypeDescription
—dict | NoneParsed JSON dict, or None if no valid block found.

_clean_rec

_clean_rec(rec: str) -> str

Normalise an LLM-generated recommendation string. Strips stray quotes (", ', `), leading/trailing whitespace, and uppercases the result so that startswith("KEEP" / "FLAG" / "REMOVE") works robustly even when the model wraps the value in punctuation.

ParameterTypeDefaultDescription
recstr—Raw recommendation string from LLM verdict.
OutputTypeDescription
—strCleaned, uppercased recommendation string.

Contradiction Matrix Builder

Stage A core: reads all per-hypothesis line catalogs ({idx}_lines.csv), detects doublets, and builds the Feature Contradiction Matrix used by the FeatureAuditor LLM as its primary data structure.

build_contradiction_matrix

build_contradiction_matrix(hypothesis_results: list[dict], hypothesis_dir: str, wl_min: float, wl_max: float) -> tuple[list[dict], list[dict], dict]

Build the Feature Contradiction Matrix from all hypotheses' lines.csv files. Reads every {idx}_lines.csv in hypothesis_dir/single_hypothesis/, filters to LIKELY and MARGINAL status features, groups them by (int(wl_obs), amp_sign) to align features at nearly identical wavelengths. Produces:

  • matrix_rows — one row per unique wavelength group with cross-hypothesis presence/absence cells, edge zone flags, and feature properties (type, amplitude, width class).
  • doublet_annotations — known doublet pairs (complete pairs and orphans) detected via _detect_doublets.
  • stats — summary statistics: n_rows, n_total_features, median_amplitude, top_quartile_amplitude, edge counts, hypothesis indices.

Edge detection: features at < 4000 A are flagged is_edge_blue, features at > 7800 A are flagged is_edge_red. Width classification: broad > 2000 km/s, narrow < 2000 km/s.

ParameterTypeDefaultDescription
hypothesis_resultslist[dict]—List of hypothesis result dicts, each containing hypothesis_idx and redshift.
hypothesis_dirstr—Root directory containing single_hypothesis/ subdirectory with per-hypothesis CSVs.
wl_minfloat—Blue edge of spectrum (first wavelength value).
wl_maxfloat—Red edge of spectrum (last wavelength value).
OutputTypeDescription
matrix_rowslist[dict]Matrix rows: each dict has wl_obs, group_key, cells (hypothesis-index-to-feature map), n_hypotheses, is_edge_blue, is_edge_red, row_type, row_amp, row_width.
doublet_annotationslist[dict]Doublet annotations from _detect_doublets.
statsdictSummary statistics: n_rows, n_total_features, n_edge_blue, n_edge_red, median_amplitude, top_quartile_amplitude, hypothesis_indices.

_detect_doublets

_detect_doublets(features_by_hyp: dict[int, list[dict]], redshift_by_hyp: dict[int, float]) -> list[dict]

Detect known doublet pairs (and orphans) within each hypothesis using DOUBLET_DEFS. For each hypothesis and each doublet definition, reports:

  • Complete pairs — both components claimed. Separation and amplitude ratio are pre-computed; mismatches between the observed and expected ratios are strong evidence against the identification.
  • Orphans — only one component claimed. The missing component's expected lambda_obs is computed from the hypothesis redshift; the LLM should check whether a real feature exists at that position.
ParameterTypeDefaultDescription
features_by_hypdict[int, list[dict]]—Features grouped by hypothesis index, each with name, wl_obs, amplitude.
redshift_by_hypdict[int, float]—Redshift per hypothesis index for computing expected separations.
OutputTypeDescription
—list[dict]Annotations: each dict has hypothesis_idx, complete, component names/wavelengths/amplitudes, ratio, note, expected and actual separations (for complete pairs); or claimed, missing, wl_missing (for orphans).

Emission–Absorption Pair Detection

Helpers that detect when the same species is claimed as both emission and absorption within a hypothesis, requiring a composite profile check during the feature audit. The species checked are Mg II, H-alpha, and H-beta.

MethodDescription
_detect_emission_absorption_pairs (matrix_rows: list[dict], hypothesis_results: list[dict]) -> list[dict]. Detect emission-absorption pairs of the same species within each hypothesis. Returns list of dicts with hypothesis_idx, species, wl_em, wl_abs, status_em, status_abs.
_group_features_by_hypothesis (matrix_rows: list[dict]) -> dict. Group matrix row cells by hypothesis index, flattening into feature dicts with name, wl_obs, status.
_build_emission_absorption_pairs_section (matrix_rows: list[dict], hypothesis_results: list[dict]) -> str. Build the "Emission-Absorption Pairs" markdown section for the FeatureAuditor user prompt. Calls _detect_emission_absorption_pairs and formats a table if pairs exist, or returns a "none detected" message.

User Message Builders

Construct the large, detailed user prompts for both audit stages. These are the primary interfaces between the pipeline and the LLM agents, providing spectrum metadata, contradiction matrices, doublet annotations, and structured task instructions.

_build_feature_audit_user_message

_build_feature_audit_user_message(state: SpectroState, hypothesis_dir: str, matrix_rows: list[dict], doublet_annotations: list[dict], stats: dict) -> str

Build the user prompt for Stage A — cross-hypothesis feature verification (FeatureAuditor). The prompt contains:

  • Spectrum metadata — wavelength range, blue/red edge zones
  • Feature statistics — total features, unique rows, edge counts, median/top-quartile amplitude
  • Hypothesis summary — redshifts per hypothesis
  • Feature Contradiction Matrix — formatted markdown table with one row per unique observed wavelength, showing which hypothesis claims each feature with type/amplitude/width annotations
  • Doublet Pairs & Orphans — structured list of complete pairs and orphans from _detect_doublets
  • Emission-Absorption Pairs section — from _build_emission_absorption_pairs_section
  • Task instructions — 8-step methodology, batch reading requirements, Three-Question Test, composite profile check mandate
ParameterTypeDefaultDescription
stateSpectroState—Full pipeline state containing spectrum arrays and hypothesis results.
hypothesis_dirstr—Harness output directory.
matrix_rowslist[dict]—Rows from build_contradiction_matrix.
doublet_annotationslist[dict]—Doublet annotations from _detect_doublets.
statsdict—Feature statistics from build_contradiction_matrix.
OutputTypeDescription

_build_synthesis_audit_user_message

_build_synthesis_audit_user_message(state: SpectroState, hypothesis_dir: str) -> str

Build the user prompt for Stage B — synthesis verdict audit (AnalysisAuditor). This comprehensive prompt includes:

  • Spectrum metadata — wavelength range, median SNR, edge zones
  • Hypothesis Synthesis Verdict — JSON dump of state['hypothesis_analysis']
  • Line Inventory — formatted markdown table from hypothesis_synthesis/catalog.csv via _format_synthesis_csv
  • Per-hypothesis cleaned line tables — post-FeatureAuditor cleaned CSVs showing KEEP/FLAG/REMOVED annotations
  • Merged verified features — all KEEP features across all hypotheses, deduplicated by wavelength, with winner-explained/unexplained annotations
  • Continuum description — from the VisualInterpreter pipeline
  • FA notes — spectrum quality assessment, global issues, structured verdicts (composite profiles, doublets, O II morphology, Ly-alpha forest)
  • Task instructions — Layer 1 physical sanity screening, completeness check (mandatory), Layer 2 targeted verification, null-result fallback for spectral classification

Contains the local function _filter_by_hypotheses(verdicts, key="hypothesis_idx") for filtering verdict dicts to only the audited hypotheses (used internally to scope FA structured verdicts to winning + excluded hypotheses).

ParameterTypeDefaultDescription
stateSpectroState—Full pipeline state with synthesis verdict, FA verdict, and spectrum data.
hypothesis_dirstr—Harness output directory containing synthesis CSVs and line tables.
OutputTypeDescription
—strComplete markdown user prompt for the AnalysisAuditor LLM.

_build_merged_verified_features

_build_merged_verified_features(hypothesis_dir: str, best_idx: int | None = None) -> str

Build a unified markdown table of all KEEP features across all hypotheses. Reads every {idx}_lines_cleaned.csv (falling back to {idx}_lines.csv), collects KEEP features, deduplicates by observed wavelength (within 2 A), and shows which hypotheses claim each feature with winner-explained/unexplained annotations. The auditor uses this to answer which real features the winning hypothesis does NOT explain.

LLM Agent Runner

The shared async runner that manages the LLM agent lifecycle for both audit stages, including streaming, truncation detection, continuation, and non-streaming fallback.

_run_llm_agent

async _run_llm_agent(system_prompt: str, user_prompt: str, tools: list, hypothesis_dir: str, stream_filename: str, stream_title: str, json_keys: list[str], log_prefix: str = "") -> dict | None

Run an LLM agent with streaming, truncation detection, continuation, and non-streaming fallback. Creates a ChatOpenAI client from env config, builds a LangChain agent with provided tools and system prompt, runs streaming with markdown output, detects truncation via run_continuation_streaming + _build_continuation_prompt, concatenates AI message content, and parses JSON via _extract_json_block. Falls back to non-streaming agent.ainvoke with continuation if streaming fails.

toolslist—LangChain tool definitions for the agent.
hypothesis_dirstr—Root directory where stream files are written.
stream_filenamestr—Relative path for the streaming markdown log (e.g. feature_auditor/stream.md).
stream_titlestr—Title for the stream markdown document.
json_keyslist[str]—Expected JSON keys for _extract_json_block and schema-aware continuation.
log_prefixstr""Prefix for warning log messages.
OutputTypeDescription
—dict | NoneParsed JSON dict from the LLM response, or None on failure.

class FeatureAuditor

Inherits: BaseAgent

Stage 3A — Cross-hypothesis feature verification before synthesis. Reads all per-hypothesis line catalogs, builds a contradiction matrix, spawns an LLM with spectrum-reading tools to independently verify whether each claimed feature is real or noise. run

async run(self, state: SpectroState) -> SpectroState

Main entry point for Stage A feature audit. Resolves harness_dir, calls build_contradiction_matrix to read hypothesis line catalogs. If no LIKELY/MARGINAL features found, sets feature_audit_verdict.skipped=true and returns early. Otherwise builds user prompt via _build_feature_audit_user_message, loads system prompt from feature_audit_skill.md, creates closure @tool functions (read_spectrum_region, detect_oii_slope_change) plus grep_kb, runs _run_llm_agent with up to 3 retries on JSON parse failure, writes cleaned CSVs via _write_cleaned_csvs, and logs the verdict summary.

ParameterTypeDefaultDescription
stateSpectroState—Pipeline state containing spectrum, hypothesis results, and output paths.
OutputTypeDescription
stateSpectroStateUpdated state with feature_audit_verdict populated (verdict dict with feature_verdicts, spectrum_quality, doublet_verdicts, etc.).

class AnalysisAuditor

Inherits: BaseAgent

Stage 3B — Adversarial second reviewer for the synthesis verdict. Takes the synthesis output (rule_analysis + hypothesis_results) and independently stress-tests the winning hypothesis by reading the raw spectrum. Outputs a calibrated verdict: CONFIRM / DOWNGRADE / REJECT / UNCERTAIN. Agent name set to "AnalysisAuditor". Skills loaded from harness/skills/AnalysisAuditor/.

run

async run(self, state: SpectroState) -> SpectroState

Main entry point for Stage B synthesis audit. Guards: if no valid synthesis verdict (redshift is None), sets verdict to SKIPPED/UNCERTAIN and returns early. Otherwise resolves harness_dir, builds user prompt via _build_synthesis_audit_user_message, loads system prompt from result_auditor_skill.md, builds CWT catalog, creates closure @tool functions (read_spectrum_region, detect_oii_slope_change, query_cwt_catalog), runs _run_llm_agent, stores result in state['auditor_verdict_json'] and state['auditor_verdict'].
