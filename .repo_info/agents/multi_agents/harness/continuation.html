Harnesscontinuation

Path: src/FORMA/agents/multi_agents/harness/continuation.py

Shared truncation-detection and continuation-loop logic used by single_hypothesis, hypothesis_synthesis, and AnalysisAuditor to handle LLM output truncation (finish_reason=length). Supports both streaming (agent.astream) and non-streaming (agent.ainvoke / agent.invoke) paths, with automatic retry when the continuation itself is truncated.

_find_last_content_ai_message

_find_last_content_ai_message(messages: list) -> Message | None

Return the last AI message that has non-empty text content. When the agent makes tool calls, the final AI message may be a tool-call-only message with empty content. This helper skips those and returns the last AI message that actually contains text (e.g., the truncated JSON output that needs continuation).

ParameterTypeDefaultDescription
messageslist—Message history to search
OutputTypeDescription
msgMessage | NoneLast AI message with text content, or None if none found

_is_truncated

_is_truncated(messages: list, *, since: int = 0) -> bool

Check whether any AI message was truncated by max_tokens (finish_reason == "length"). Scans ALL AI messages (not just the last one) because in multi-turn tool-calling agents, truncation may happen in an intermediate turn while the final turn completes normally (e.g., a tool-only final message with finish_reason=stop).

ParameterTypeDefaultDescription
messageslist—Message history to inspect
sinceint0Only check messages from this index onward; used by continuation loops to avoid re-detecting truncation markers from the original (already-handled) run
OutputTypeDescription
truncatedboolTrue if any AI message has finish_reason == "length"

run_continuation_streaming

async run_continuation_streaming(agent, accumulated_messages: list, *, config: dict, stream_md_path: Optional[str] = None, continuation_prompt: str = "", max_attempts: int = 3, log_prefix: str = "") -> list

Primary async entry point. Run the truncation-continuation loop using agent.astream. Appends all continuation messages (AI + tool) to accumulated_messages in-place. When stream_md_path is set, writes turn-by-turn markdown including tool calls and results.

ParameterTypeDefaultDescription
agentlangchain agent—LangChain agent instance
accumulated_messageslist—Live message list from the original streaming run (mutated in-place)
configdict—Agent config (recursion_limit, etc.)
stream_md_pathstr | NoneNoneIf set, append continuation output to this file
continuation_promptstr""Prompt for the first continuation attempt. On 2nd+ attempts a terse retry prompt is used automatically
max_attemptsint3Maximum number of continuation attempts
log_prefixstr""Prefix for log messages (e.g. "FeatureAuditor")
OutputTypeDescription
messageslistThe mutated accumulated_messages (same object)
