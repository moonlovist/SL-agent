_lookup_wavelength_errors

_lookup_wavelength_errors(harness_dir: str, output_dir: str) -> dict

Look up wavelength_error for each unique wavelength across all line CSVs. Reads {idx}_lines.csv, {idx}_lines_cleaned.csv from harness_dir/single_hypothesis/, and visual_interpreter/{spectrum_id}_emission.csv / {spectrum_id}_absorption.csv from output_dir. Builds a mapping from integer-rounded wavelength to wavelength_err. Only the first encountered error for each wavelength is kept.

ParameterTypeDefaultDescription
harness_dirstr—Harness output directory containing single_hypothesis/ subdirectory with per-hypothesis line CSVs
output_dirstr—Root output directory containing visual_interpreter/ CSVs
OutputTypeDescription
errorsdict{int(wavelength): wavelength_err} mapping from integer-rounded observed wavelength to its measurement error

_format_confirmed_lines_with_errors

_format_confirmed_lines_with_errors(confirmed_lines: list, wavelength_errors: dict) -> str

Format the confirmed lines list with their associated wavelength errors into a markdown bullet list. Each entry shows line name, observed wavelength, and error (or "error unknown" if not found). Returns *(no confirmed lines)* for empty input.

ParameterTypeDefaultDescription
confirmed_lineslist—List of [line_name, wavelength] pairs from the Result Auditor verdict
wavelength_errorsdict—{int(wavelength): error} from _lookup_wavelength_errors
OutputTypeDescription
formattedstrMarkdown bullet list of confirmed lines with error annotations

_extract_json_from_text

_extract_json_from_text(text: str) -> Optional[dict]

Extract a JSON object from raw LLM output text. Tries three strategies in order: (1) a JSON fenced code block (```json ... ```), (2) any fenced code block, (3) a bare JSON object containing a "type" string key, (4) parsing the entire text as JSON. Returns None if all strategies fail.

ParameterTypeDefaultDescription
textstr—Raw LLM output text potentially containing embedded JSON
OutputTypeDescription
resultdict | NoneParsed JSON dict, or None if extraction fails

_write_stream

_write_stream(md: TextIOWrapper, messages: list) -> None

Write conversation messages to a streaming markdown file. Iterates through agent messages and writes LLM text responses, tool call arguments (as JSON), and tool results (truncated to 2000 chars) to the open file handle. Skips human-role messages (the initial user prompt was already written by the caller).

ParameterTypeDefaultDescription
mdTextIOWrapper—Open file handle to the stream markdown file
messageslist—List of LangChain message objects with type, content, tool_calls, and name attributes
OutputTypeDescription
—NoneWrites markdown content to the file handle in-place

_build_user_message

_build_user_message(state: SpectroState, harness_dir: str) -> str

Build the user prompt for the Report Writer LLM. Assembles a structured markdown prompt containing: spectrum metadata (wavelength range, median SNR, blue/red edges), continuum description, synthesis verdict (best hypothesis, redshift, classification, confidence, anchor line, excluded hypotheses), Result Auditor verdict (calibrated confidence, spectrum quality, key issues), confirmed lines with wavelength errors, per-hypothesis line tables (post-FeatureAuditor), FA structured verdicts (composite profiles, doublets, [O II] morphology), and a final task description instructing the LLM to produce the 6-section report.

ParameterTypeDefaultDescription
stateSpectroState—Shared pipeline state containing spectrum data, hypothesis analysis, auditor verdicts, continuum, and feature audit results
harness_dirstr—Harness output directory for resolving CSV paths and the report save location
OutputTypeDescription
promptstrStructured markdown user prompt for the report-writing LLM

arun

async arun(state: SpectroState, harness_dir: str, *, model: str = "deepseek-v4-pro", api_key: Optional[str] = None, base_url: Optional[str] = None, temperature: float = 0.3, max_turns: int = 30, stream_md_path: Optional[str] = None) -> Tuple[str, Optional[dict]]

Run the Report Writer report-writing agent. Loads the skill prompt, builds the user prompt, configures the LLM (with thinking disabled via _build_thinking_extra_body), creates a LangChain agent with compute_redshift_error and write_report tools, invokes the agent asynchronously, optionally streams the full conversation to a markdown file, and extracts the final report text plus any comprehensive assessment JSON from the last AI message. Returns both artifacts for downstream use.

ParameterTypeDefaultDescription
stateSpectroState—Shared pipeline state with spectrum data, synthesis results, auditor verdicts, feature audit outputs
harness_dirstr—Harness output directory for CSVs, skill files, and report output
modelstr"deepseek-v4-pro"LLM model identifier passed to the chat creation function
api_keystr | NoneNoneAPI key for LLM authentication
base_urlstr | NoneNoneCustom API base URL; used for vendor detection and thinking configuration
temperaturefloat0.3LLM sampling temperature
max_turnsint30Maximum recursion / turn limit for the agent loop
stream_md_pathstr | NoneNoneIf set, writes the full conversation (system prompt, user prompt, tool calls, results, final output) to this markdown file
OutputTypeDescription
report_markdownstrFinal report as raw markdown text from the last AI message
comprehensive_assessmentdict | NoneExtracted JSON comprehensive assessment block, or None if parsing fails
