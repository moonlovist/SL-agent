Rest-Frame Line Tables

Single source of truth for rest-frame spectral line data, kept in sync with VI.py. These dictionaries define every line the system can predict, fit, and classify.

dict[str, float]

14 absorption lines keyed by name with rest-frame wavelength in Å. Includes Ca H/K, G-band, Mg I, Mg II, Na D, Ca triplet, and Balmer absorption lines.

dict[str, float]

dict[str, tuple]

dict[str, Path]

Maps searchable knowledge-base file names to their Path objects under kb/: classification.md, ionization.md, lines.md, composite_profile.md.

Tool Functions

All 12 functions are decorated with @tool and registered with the agent runtime for LLM invocation.

load_spectrum

load_spectrum(npz_path: str) -> dict

Load a cleaned spectrum .npz file and return summary statistics. The file must contain arrays: wavelength, flux, snr (and optionally ivar). Detects distinct spectral bands by looking for gaps >100 Å in the wavelength coverage.

ParameterTypeDefaultDescription
npz_pathstr—Absolute path to the cleaned .npz file
OutputTypeDescription
n_pointsintNumber of wavelength bins
wavelength_minfloatMinimum wavelength (Å)
wavelength_maxfloatMaximum wavelength (Å)
snr_medianfloat or NoneMedian SNR across the spectrum
n_armsstr or NoneNumber of distinct spectral bands (if detectable)

predict_lines

predict_lines(redshift: float, line_type: str = "all", wavelength_min: float = None, wavelength_max: float = None) -> dict

Predict observed-frame wavelengths for all rest-frame spectral lines at a given redshift. Optionally filter to a wavelength range. Sorts results by observed wavelength. Returns both emission and absorption lines unless line_type restricts.

ParameterTypeDefaultDescription
redshiftfloat—The redshift hypothesis z
line_typestr"all""emission", "absorption", or "all"
wavelength_minfloat or NoneNoneLower bound for λ_obs (Å)
wavelength_maxfloat or NoneNoneUpper bound for λ_obs (Å)
OutputTypeDescription
redshiftfloatThe input redshift
n_linesintNumber of lines in the result
lineslist[dict]Each dict: name, rest_wl, obs_wl, width_class, type

fit_peak

fit_peak(npz_path: str, center_guess: float, width_3sigma: float, line_type: str = "emission", window_half: float = 200.0) -> dict

Fit a Gaussian + linear baseline model around a predicted line position. Loads the spectrum from .npz, extracts a fitting window centered on the guess, and runs bounded curve_fit. The amplitude sign is constrained by line_type (emission ≥ 0, absorption ≤ 0).

ParameterTypeDefaultDescription
npz_pathstr—Path to the cleaned spectrum .npz file
center_guessfloat—Predicted observed wavelength (Å) — initial guess for Gaussian center
width_3sigmafloat—Expected physical width (3σ) of the line in Å. Typical: broad=90, narrow=25, both=50, absorption=20
line_typestr"emission""emission" (amp ≥ 0) or "absorption" (amp ≤ 0)
window_halffloat200.0Half-width of the fitting window in Å
OutputTypeDescription
centerfloat or NoneFitted Gaussian center (Å)
center_errfloat or NoneUncertainty on center (Å)
amplitudefloat or NoneGaussian amplitude
amplitude_errfloat or NoneUncertainty on amplitude
sigmafloat or NoneGaussian σ (Å)
fwhmfloat or NoneFWHM = 2.35482 × σ (Å)
fwhm_km_sfloat or NoneFWHM in km/s
delta_chi2_per_nfloat or None(χ²_linear − χ²_full) / n
local_rmsfloat or NoneRobust RMS of residuals (MAD-based)
local_snrfloat or None|amp| / local_rms
n_pointsintNumber of points in the fitting window
flagslist[str]Warning flags (e.g. center_deviation_large)
messagestrHuman-readable fit summary

OutputTypeDescription

grep_kb

grep_kb(pattern: str, A: int = 0, B: int = 0, C: int = 0) -> dict

Search the knowledge base and skill files with a grep-compatible regex pattern and optional context lines. Use this to check what the pipeline methodology, physics rules, and classification criteria actually say. Essential for distinguishing skill_gap (rule missing from doc) from llm_error (LLM ignored a documented rule). Returns match blocks with line numbers and context.

ParameterTypeDefaultDescription
patternstr—Grep-compatible regex (case-insensitive)
Aint0Lines to show AFTER each match (like grep -A)
Bint0Lines to show BEFORE each match (like grep -B)
Cint0Lines before AND after (like grep -C). A/B take precedence over C
OutputTypeDescription
resultsdict[str, list]Filename → list of match blocks. Each block is list[str] of "L<num>>: <text>". Returns {"(no matches)": []} if nothing found

detect_oii_slope_change

detect_oii_slope_change(npz_path: str, target_wl: float, search_window: float = 25.0) -> dict

Detect the [O II] unresolved doublet slope-change signature at a target wavelength. [O II] 3727 is a close doublet (3726.0/3729.0 Å, rest sep 2.8 Å) unresolved at DESI resolution. Its discrete derivative on the rising edge shows a characteristic dip — rising, dropping significantly, then rising again. A true single line cannot produce this pattern. Use to discriminate [O II] from [O III]b when the same observed feature is claimed by competing hypotheses.

ParameterTypeDefaultDescription
npz_pathstr—Path to the cleaned spectrum .npz file
target_wlfloat—Observed wavelength (Å) where [O II] is claimed
search_windowfloat25.0Half-width of the search window (Å)
OutputTypeDescription
detectedboolTrue if slope-change or valley signature found
signature_typestr or None"valley" (flux reversal) or "slope-change" (derivative dip)
peak_wlfloatActual peak wavelength (Å)
peak_fluxfloatPeak flux value
dip_ratiofloatdip_deriv / max_deriv (< 0.20 = detected slope-change)
dip_thresholdfloatThreshold used for dip detection
max_derivfloatMaximum derivative on the rising edge
max_deriv_wlfloatWavelength of max derivative
dip_derivfloatMinimum derivative after the max
dip_wlfloatWavelength of the dip
recovery_derivfloatMax derivative after the dip
recovery_wlfloat or NoneWavelength of recovery peak
recovery_okbool or NoneTrue if recovery meets threshold
fwhm_Afloat or NoneFWHM estimate (Å)
fwhm_km_sfloat or NoneFWHM estimate (km/s)
deriv_profilelist[float]Full derivative array on the rising edge
deriv_wllist[float]Wavelengths for derivative array
n_rise_pixelsintNumber of pixels in the rising edge
n_deriv_pointsintNumber of derivative points
n_post_dipintNumber of derivative points after dip

compute_redshift_error

compute_redshift_error(rest_wavelength: float, wavelength_error: float) -> dict

Compute the redshift uncertainty σ_z from a line's wavelength error: σ_z = wavelength_error / rest_wavelength. Use the ANCHOR line (lowest-ionization confirmed line) for the most reliable σ_z estimate.

ParameterTypeDefaultDescription

wavelength_errorfloat—Wavelength measurement uncertainty (Å), from CWT catalog wavelength_err
OutputTypeDescription
sigma_zfloatRedshift uncertainty σ_z (6 d.p.)
rest_wavelengthfloatInput rest wavelength
wavelength_errorfloatInput wavelength error

Internal Helpers

Module-level helper functions supporting the tool layer. Grouped by domain: fitting core routines, CSV utilities, knowledge-base loading, and detection logic.

Fitting Model Functions

_gaussian_plus_linear

_gaussian_plus_linear(x, amp, center, sigma, slope, intercept) -> ndarray

Gaussian plus linear baseline model: amp * exp(-(x - center)^2 / (2 * sigma^2)) + slope * x + intercept. Used as the fitting function for curve_fit in all single-peak fits.

_doublet_model

_doublet_model(x, amp1, center1, sigma1, amp2, center2, sigma2, slope, intercept) -> ndarray

Two-Gaussian plus linear baseline model. Used for doublet fitting where λ separation is known and the two components may partially overlap.

Attempt a single-Gaussian fit on a sub-array. Returns a compact result dict (center, amplitude, sigma, fwhm, fwhm_km_s) or None on failure. Used as the fallback path inside _do_fit_doublet when the full 8-parameter fit fails.
