Harnesshypothesis_synthesis

Path: src/FORMA/agents/multi_agents/harness/hypothesis_synthesis.py

LLM-driven redshift hypothesis synthesis. Cross-compares multiple harness reports (one per redshift hypothesis), optionally reads raw spectrum regions, and delivers a final combined verdict. This is Phase 2 of the HypothesisAnalyst pipeline (Phase 1 = per-hypothesis runs via single_hypothesis.py).

Dependencies: tools · continuation · HA · AnalysisAuditor

Public API

arun

async arun(harness_results: list, wl: ndarray, fl: ndarray, harness_dir: str, *, snr: ndarray | None = None, model: str | None = None, api_key: str | None = None, base_url: str | None = None, temperature: float = 0.1, max_turns: int = 150, stream_md_path: str | None = None, summaries: list[str] | None = None, mode: str = "nomad", report_path: str | None = None, csv_path: str | None = None, feature_audit_verdict: dict) -> dict

Main entry point. Runs the LLM synthesis agent over multiple harness reports. Loads the skill prompt, builds the user message with FeatureAuditor results, constructs an agent with read_spectrum_region, grep_kb, write_report, and write_synthesis_csv tools, and executes the agent. Supports a streaming mode that writes the full conversation (system prompt, every LLM turn, tool calls, tool results) to a markdown file in real time. Detects truncation and runs continuation loops to gather partial responses. Parses the final JSON verdict block from the accumulated LLM output.

ParameterTypeDefaultDescription
harness_resultslist—Results from per-hypothesis harness runs. Each dict has keys: hypothesis_idx, redshift, report, structured_output, feature_catalog, and optionally error
wlndarray—Wavelength array for the spectrum
flndarray—Flux array for the spectrum
harness_dirstr—Directory containing per-hypothesis {idx}_report.md files (fallback if report text not in harness_results)
snrndarray | NoneNoneSNR array; used for median SNR line in the user prompt
modelstr | NoneNoneLLM model name; defaults to LLM_MODEL env var or "deepseek-v4-pro"
api_keystr | NoneNoneAPI key; defaults to LLM_API_KEY env var
base_urlstr | NoneNoneAPI base URL; defaults to LLM_BASE_URL env var or DeepSeek endpoint
temperaturefloat0.1LLM temperature
max_turnsint150Maximum agent turns / recursion limit
stream_md_pathstr | NoneNoneIf set, stream the full conversation (system prompt + all LLM turns + tool calls + results) to this .md file in real time
summarieslist[str] | NoneNonePre-built markdown summaries (one per hypothesis); built via extract_harness_summary if None
modestr"nomad""nomad" or "redrock"; controls mode-specific notes in the prompt
report_pathstr | NoneNoneOutput path for the synthesis report markdown
csv_pathstr | NoneNoneOutput path for the synthesis CSV
feature_audit_verdictdict—FeatureAuditor verdict JSON (keyword-only, required)
OutputTypeDescription
verdictdictParsed synthesis verdict with keys: redshift, anchor_line, anchor_wavelength, wavelength_error, classification, confidence, best_hypothesis_idx, primary_evidence, excluded_hypotheses, caveats. On failure, returns a fallback dict with null redshift and LOW confidence.
