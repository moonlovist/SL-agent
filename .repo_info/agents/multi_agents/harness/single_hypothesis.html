Harnesssingle_hypothesis

Path: src/FORMA/agents/multi_agents/harness/single_hypothesis.py

LLM-driven targeted line search harness. Equips an LLM with 5 spectrum-analysis tools and a methodology skill prompt. The LLM autonomously confirms or refutes predicted spectral lines at a given redshift hypothesis through targeted Gaussian fitting. Supports both synchronous and async/streaming execution with HTTP retry and truncation continuation.

_is_retryable

_is_retryable(exc: Exception) -> bool

Check whether an HTTP exception is worth retrying. Scans the exception message for known retryable keywords such as 429, 5xx, timeout, connection, reset, refused, EOF, and broken pipe. Used by both run and arun to implement HTTP-level retry loops with exponential backoff.

ParameterTypeDefaultDescription
excException—The caught exception whose message is checked for retryable patterns
OutputTypeDescription
retryableboolTrue if the lowercased exception message contains any retryable keyword

_resolve_max_tokens

_resolve_max_tokens() -> int | None

Resolve the max_tokens parameter from the LLM_MAX_TOKENS environment variable. When the env var is unset or empty and the provider is DeepSeek (detected from LLM_BASE_URL), defaults to 65536 to prevent output truncation that causes "insufficient tool messages following tool_calls" errors.

OutputTypeDescription
max_tokensint | NoneParsed token limit, or 65536 for DeepSeek providers, or None if unset

_build_tools

_build_tools(mode: str = "nomad", npz_path: str = None) -> list

Return the tool list appropriate for the verification mode. In "nomad" mode, exposes only write_report and write_lines_csv (CWT evaluation). In "redrock" mode, adds _fit_peak, _fit_doublet, and compute_redshift tools; the spectrum arrays are captured via closure so the LLM passes only physical parameters.

Closure tools (redrock mode):

  • _fit_peak(center_guess, width_3sigma, line_type="emission", window_half=200.0) -> dict — Fit a single Gaussian + linear baseline around a predicted line position. Delegates to _do_fit_peak.
  • _fit_doublet(center_guess_1, center_guess_2, line_type="emission", width_3sigma=25.0, window_half=300.0, separation_rest=None, separation_tolerance=5.0, amp_ratio_expected=None) -> dict — Fit two Gaussians + linear baseline for close line pairs (Ca H/K, [O III]a/b, [S II]a/b, [N II]a/b, Na D). Delegates to _do_fit_doublet.
ParameterTypeDefaultDescription
modestr"nomad"Verification mode; controls which tools are included
npz_pathstr | NoneNonePath to cleaned spectrum .npz; required in redrock mode for closure-captured arrays
OutputTypeDescription
toolslistList of LangChain @tool-decorated callable tools

_mask_overlap_label

_mask_overlap_label(lo: float, hi: float, obs_wl: float, masked_regions: list | None) -> str

Return a label describing how the z-verification window [lo, hi] overlaps with masked spectral regions. Returns empty string if no overlap. Labels include [fully masked] when the entire window is masked, [lambda_pred masked] when the nominal line position is masked, and [window partially masked] for partial overlap.

ParameterTypeDefaultDescription
lofloat—Lower bound of the z-verification window in observed Angstroms
hifloat—Upper bound of the z-verification window
obs_wlfloat—Nominal observed wavelength of the predicted line
masked_regionslist | None—List of [start, end] tuples for masked wavelength ranges
OutputTypeDescription
labelstrMask overlap annotation or empty string if no overlap

_find_nearby_features

_find_nearby_features(rest_wl: float, obs_wl: float, z_min: float, z_max: float, peaks: list, troughs: list) -> str

Find CWT-detected peaks and troughs whose wavelength falls within the z-verification window for a given rest-frame line. Results are sorted by distance to the observed line wavelength (closest first). Returns brief references like peak@5001.2+-0.3(z=0.0085).

ParameterTypeDefaultDescription
rest_wlfloat—Rest-frame wavelength of the spectral line in Angstroms
obs_wlfloat—Observed wavelength of the predicted line
z_minfloat—Lower bound of redshift verification window
z_maxfloat—Upper bound of redshift verification window
peakslist—List of CWT-detected emission peaks
troughslist—List of CWT-detected absorption troughs
OutputTypeDescription
refsstrComma-separated feature references, or em-dash if none found

Async entry point with optional streaming support. Behaves identically to run but supports a stream_md_path parameter: if set, streams the full conversation (system prompt, every LLM turn, tool calls, tool results) to a Markdown file in real time using agent.astream with stream_mode="updates". HTTP retry and truncation continuation are handled identically to the sync path. When not streaming, uses agent.ainvoke as the async counterpart of agent.invoke.
