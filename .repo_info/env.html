Configuration.env

Path: .env (project root)

All runtime configuration is driven by environment variables, loaded via python-dotenv and parsed by Pydantic models in src/FORMA/core/config/. See .env_example for a complete template.

Dependencies: Config System · _utils

SelfEvolve — in design

Architecture not yet complete. The failure analysis loop and batch root-cause identification are scaffolded but not fully wired.

KeyTypeEnv VarDefaultDescription
self_evolveboolSELF_EVOLVEFalseEnable SelfEvolve failure analysis loop
failure_batch_sizeintFAILURE_BATCH_SIZE5Pending failure threshold to trigger batch analysis
z_tolerancefloatZ_TOLERANCE0.005Acceptable redshift error for ground-truth comparison
—floatEXPECTED_Z—Ground-truth redshift for the current sample
—strEXPECTED_TYPE—Ground-truth classification: QSO, Galaxy (ELG), Galaxy (LRG/BGS), Star
Note: EXPECTED_Z and EXPECTED_TYPE are per-sample ground-truth values read directly from env vars by SelfEvolve.run(), not stored in any Pydantic config model. They are only consumed when SELF_EVOLVE=true.
