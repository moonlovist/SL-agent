# LensAgent 当前版本说明

> 当前版本：`0.9.0`
>
> Observation schema（观察文档格式）：`1.7`
>
> 本次主题：把旧后验环模板重构为统一的几何路径引导搜索

## 本次改变了什么

原v0.8环通道容易让人误解为“评价完整椭圆是不是环”。本版本按照谭老师提出的model-driven思路及后续讨论重新定义其职责：圆/椭圆只是搜索路线，用来提示程序在何处继续寻找真实弧段，不代表整条路线都有结构。

正式流程现在只有一个`GeometricPathSearch`（几何路径引导搜索）模块：

1. SEP先提供已检测残差结构；
2. 如果已有弧状结构，使用其像素、宽度、中心星系位置及PSF估计一组受约束圆/椭圆路线；
3. 如果没有可靠种子，则由同一模块使用中心参考后备路线，不另建一套环检测器；
4. 沿路线附近复用当前残差S/N低门槛寻找未被全局SEP结构列表收录的独立像素段；
5. 原种子、已有关联结构、搜索路线和新找到的像素段分别记录，避免重复计数；
6. 第一版只搜索一轮，不让新噪声不断反向扩张路线。

## 输出怎样理解

- `G1/G2/...`是搜索路线，不是环、弧或强透镜结论；
- `S1/S2/...`是SEP等原流程已经测得的结构；
- `G1N1/G1N2/...`才是沿路线新找到的真实残差像素段；
- 路线空白处不算“存在结构”；
- 没找到新弧不反对透镜假设；
- 找到新弧也不自动支持透镜，需要后续比较几何、颜色、PSF、前景模型稳定性及替代解释。

## 当前流程

```text
FITS / PNG
→ 图像、RMS、PSF、WCS与中心定位
→ 前景星系建模与减除
→ 残差与残差S/N
→ S/N多阈值 + SEP多参数共识
→ 通用残差结构S1/S2/...
→ 几何路径引导搜索G1/G2/...
→ 新恢复像素段G1N1/G1N2/...
→ Observation
→ 多假设推理、审计和报告
```

## 新增可追溯文件

- `vision_geometric_path_search.png`：蓝线显示搜索路线，洋红像素显示沿路线新找到的实际结构；
- `observation.json → geometric_paths`：记录启动方式、种子结构、路线几何、搜索半宽、拟合离散、已有关联结构和新恢复像素段；
- `vision_artifacts.npz → geometric_path_mask_G*`：精确搜索带像素；
- `vision_artifacts.npz → geometric_path_recovered_mask_G*`：新恢复像素；
- `observation_summary_cn.md`：用中文分别解释路线和真实新结构。

## 参数边界

- 本版本没有添加“覆盖多少算环”或“S/N多高算透镜”的新判定阈值；
- 路径恢复复用视觉层已有的低S/N结构门槛，新增模块不自行创造第二套科学分界线；
- 搜索半宽至少覆盖原设定宽度，并根据种子拟合离散和实际PSF自动放宽；
- 圆/椭圆参数仍需通过专家标注、确定非环困难样本和注入恢复实验进行标定；
- 本版本只验证算法行为，不宣称A/B/C准确率提高。

## 方法来源与科研边界

- 直接需求来源：谭老师在项目会议中提出“由已检出弧构造圆/椭圆，并沿带宽路径继续检查S/N”的后验搜索思路；王浩松师兄补充了由弧反推中心、曲率并迭代视觉流程的实现建议。项目讨论随后明确：路径只负责提示“去哪里找”，不能用来证明整条环存在。
- 已有研究依据：Joseph等（2014）的[PCA强透镜搜索方法](https://doi.org/10.1051/0004-6361/201423365)同样在前景星系减除后的残差图中利用以星系中心为参考的几何变换，增强完整或不完整爱因斯坦环的累积信号；其另一条通道则依据结构的方向、多重性和延展性搜索透镜像。这支持“连通域检测与几何引导搜索互补”的总体方向。
- 几何方法依据：Fitzgibbon、Pilu和Fisher（1999）的[椭圆拟合研究](https://doi.org/10.1109/34.765658)说明可以从离散点约束椭圆，但局部弧、噪声和遮挡会使结果不稳定。因此本版本没有把单个弧自由拟合成唯一椭圆，而是在中心、轴比和方向受限的路线集合中选择局部匹配较好的搜索路线。
- 本项目实现属于上述思想在当前Euclid Q1流程中的工程化扩展，不是照搬论文算法，也不是Euclid官方判定规则。路线范围和恢复结果仍必须用本项目的标注与注入实验验证。

## 下一步

1. 用少量专家明确指出弧位置的真实样本检查路线是否经过正确区域；
2. 检查新恢复像素是否为第二弧，而非前景减除残差；
3. 建立路径参数的注入恢复和负样本验证；
4. 再把新恢复弧段接入结构组合、多像关系和颜色/PSF测量；
5. 最后使用独立验证集标定A/B/C规则。
