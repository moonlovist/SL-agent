# LensAgent 当前版本说明

> 当前版本：`0.8.1`
>
> Observation schema（观察文档格式）：`1.6`
>
> 本次主题：撤回未经标定的环通道硬门槛，改为纯描述性测量

## 本次改变了什么

原有视觉层以“前景星系减除后的残差图”为输入，使用S/N多阈值和SEP多参数共识寻找通用残差结构。它能发现局部较亮的弧段、亮点或其他连通区域，但低表面亮度的完整环或不完整环可能无法形成足够显著的连通域，从而漏检。

后验环通道以测得的中心亮源为受限参考，扫描圆形和椭圆形环带；对于每个模板，沿完整环带重新采样残差S/N，并记录：

- 环带半长轴、轴比、方向和中心；
- 高于其相邻环带局部背景的角向比例；
- 高于局部背景的最长连续角度；
- 环带内S/N与相邻内外环带的S/N差；
- 该模板是否接近SEP残差结构；

它的意义是：SEP先提供局部线索；环模板再检查这些线索是否可能属于一条更完整、但大部分像素很弱的环。即使SEP没有检测到整圈，环通道仍可对以中心为参考的弱连续信号进行量化。

## 必须正确理解的边界

- 环模板候选不是“已确认爱因斯坦环”，更不是“已确认强透镜”。
- 会议中出现的`S/N ≥ 0.5`与`覆盖比例 ≥ 80%`只是解释方案的举例；v0.8.1不再使用它们，也不设置任何环模板“通过/不通过”硬门槛。
- 环通道与SEP通道都使用同一份前景减除残差图，不能作为两份相互独立的证据。
- 环模板当前不直接向任何假设提供支持或反对证据；它只为后续、经验证的推理提供可审计事实。
- A/B/C是否能对应数据集真实等级，不能由本次代码升级直接证明；必须在未参与调参的、有明确等级来源的样本上做对照测试。

## 当前视觉流程

```text
FITS / PNG
→ 读取图像、噪声、WCS与中心
→ 污染源处理、前景星系建模与减除
→ 残差图与残差S/N图
→ S/N多阈值稳定性检测
→ SEP多参数共识检测
→ 通用未分类残差结构测量
→ 后验圆/椭圆环带测量
→ 统一写入Observation
→ 多假设推理、证据审计、决策审计、报告
```

视觉层仍只回答“测到了什么”，不直接输出“透镜/非透镜”。后续推理层比较强透镜、前景星系自身结构、并合/相互作用和处理伪影等解释。

## 每次运行新增的可追溯内容

- `vision_posterior_ring_detection.png`：在残差图和残差S/N图上叠加保留的圆/椭圆模板。蓝色仅用于区分模板；没有绿色/橙色等级、没有通过/不通过结论。
- `observation.json → ring_candidates`：每个环模板的完整机器可读测量和来源。
- `vision_artifacts.npz → ring_candidate_mask_R*`：每个保留模板实际参与测量的像素环带。
- `observation_summary_cn.md`：新增“后验圆/椭圆环模板测量”中文解释段落。

原有过程文件继续保留：

- `vision_snr_threshold_process.png`：多S/N阈值过程；
- `vision_sep_consensus.png`：SEP参数共识；
- `vision_residual_structure_extraction.png`：通用残差结构提取；
- `vision_foreground_model_comparison.png`：正式前景减除与PSF-MGE审计对照；
- `vision_field_context.png`与可选`vision_rgb_context.png`：检测位置回映射；
- `vision_manifest.json`：输入指纹、参数、处理顺序与文件路径；
- `vision_artifacts.npz`：精确数值数组；
- `observation.json`、`reasoning.json`、`summary.json`、`report.md`：观察、推理、结论和报告。

## 下一步，不在本版本内宣称完成

1. 用少量来源明确的样本分别检查弧、环、多重像和典型误检；
2. 建立独立标注验证集后，再判断是否存在可用的环模板判别规则；
3. 增加多重像成组通道：位置、共同半径、PSF/延展性与多波段颜色一致性；
4. 增加结构组合通道，将SEP碎片组合为同一弧或环的可能成分；
5. 建立独立验证集，检验最终A/B/C与数据集等级的对应程度。
