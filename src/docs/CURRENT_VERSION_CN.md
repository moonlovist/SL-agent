# LensAgent 当前版本说明

> 当前版本：`0.14.0`
>
> Observation schema（观察文档格式）：`1.13`
>
> 本次主题：视觉候选四路分流与后端交接

## 本次解决了什么

上一版为了避免椭圆路线漏掉四重像等真实结构，把图4中几乎所有具有可测信号的候选都晋级给规则层。这样提高了召回，但也把前景减除残差和路线外噪声重新送进后端，尤其会污染前景建模失败的样本。

本版本保留SEP、椭圆路线二次寻找和局部分割，但不再把“检测到”直接等同于“交给当前规则层”。每个候选同时检查三类事实：

1. 它是否在配置的8层S/N阈值中保持足够大的连通结构；
2. 它是否获得椭圆路线支持或由路线内二次搜索恢复；
3. 它是否靠近减除核心，或在PSF-MGE比较模型中消失。

随后进行四路分流：

```text
SEP与椭圆Model提出完整候选池
↓
候选级S/N稳定性 + 几何支持 + 前景污染审计
├─ primary_candidate：主候选，生成structure并进入当前规则层
├─ recovery_candidate：可能是真实但证据不完整，保留供后续补充分析
├─ foreground_contaminated：疑似前景减除残差，隔离于正向透镜证据
└─ trace_candidate：弱线索，仅保留追溯
↓
当前规则层只读取primary_candidate形成的structures
```

## 椭圆路线现在起什么作用

椭圆路线仍然有两项重要作用：补找第一次SEP漏掉的弱弧、环段或像；帮助判断不同像素段是否可能位于同一几何路径附近。

但路线不再单独宣判一个信号“真实或虚假”。路线内的结构若明显受到前景减除污染，仍会进入污染通道；路线外但在多层S/N中稳定的结构会进入恢复通道，而不是被删除。这样既保留了路线排干扰的价值，也避免路线范围不准时永久丢失四重像。

## 四种结果怎样理解

| 交接类别 | 中文含义 | 进入当前`structures`/规则层 | 是否等于强透镜证据 |
|---|---|---:|---:|
| `primary_candidate` | S/N连通稳定、具有路线支持且未发现明显前景污染 | 是 | 否 |
| `recovery_candidate` | 路线外但S/N稳定，或路线支持但S/N稳定性不足 | 否，完整保留待后续调用 | 否 |
| `foreground_contaminated` | 近减除核心并具有模型风险，或换比较前景模型后消失 | 否，与正向证据隔离 | 否 |
| `trace_candidate` | 探测事实较弱，仅用于过程追溯 | 否 | 否 |

这里的“主候选”只是当前最适合交给后端解释的残差信号，不代表它已经被命名为弧、环、多重像，更不代表它一定是强透镜。

## 新增可追溯测量

每个`model_candidate`新增：

- `snr_threshold_survival_count`：候选在8个S/N阈值层中，以连通结构形式存活了几层；
- `snr_threshold_survival_fraction`：上述存活比例；
- `subtraction_core_overlap_fraction`：候选有多少像素落在前景减除敏感核心内。

每项`candidate_structure_audits`新增`handoff_class`，明确它进入哪一条交接通道；`geometry_used_for_verdict=false`仍表示几何路线不决定信号真假，`geometry_used_for_handoff`则说明路线是否参与了交接分流。

`vision_signal_audit.png`右图颜色统一为：绿色=主候选，青色=恢复候选，红色=前景污染，橙色轮廓=仅留痕。颜色只表示交接去向，不是最终等级或置信度。

## 当前边界

- 候选级多阈值存活使用现有工程配置，不是从标注数据学习出的最佳科学阈值；
- 前景模型失败仍是主要误差源，本版本只隔离明显污染，不能修复错误的前景光模型；
- 恢复候选暂不进入当前规则层，下一阶段编写分级细则时可按具体假设有条件调用，不能与主候选等权计分；
- 多波段颜色、像之间的一致性和完整透镜质量建模仍属于后续专家推理与审计；
- 本次分流验证的是架构行为，不代表ABC等级已经校准。
