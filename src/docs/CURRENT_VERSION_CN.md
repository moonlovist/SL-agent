# LensAgent 当前版本说明

> 当前版本：`0.10.1`
>
> Observation schema（观察文档格式）：`1.9`
>
> 本次主题：原始SEP结构与路线内新结构的几何认证和系统组合

## 本次纠正了什么

v0.10虽然保留了原始SEP结果，但过程图和统一掩膜更强调路线内新恢复的紫色像素，容易造成错误理解：

```text
第一次SEP找到的绿色不可靠
第二次路线内找到的紫色最可靠
```

v0.10.1明确撤回这种含义。紫色不天然比绿色可靠；几何model不是替换SEP，而是同时为SEP原有结果和新发现结果提供路线关系、结构支持来源和组合依据。

## 当前正确流程

```text
全图SEP多参数共识
├─ 原始SEP结构与合理路线一致 → SEP + geometry结构支持
└─ 原始SEP结构无路线支持 → 原始线索，待解释

几何路线内再次运行SEP
└─ 找到原SEP漏掉的像素 → 路线内补充结构支持

同一路线上的原始SEP结构 + 新恢复结构
→ candidate_system（候选结构系统）
→ 等待前景减除、PSF、颜色、标注和替代解释审计
```

`candidate_system`只表示多个结构共享同一条搜索路线，不表示它们已经被证明是同一背景源的多重像，也不表示该对象是强透镜。

## 结构支持等级

这里不用“高置信度”，避免与最终透镜判断的Confidence（可信度）混淆。

| 机器字段 | 中文含义 | 图中颜色 |
|---|---|---|
| `raw_sep_only` | SEP稳定检出，但尚无合格几何路线支持 | 橙色 |
| `sep_plus_geometry` | 原始SEP结构同时符合合理几何路线 | 绿色 |
| `route_recovered` | 原SEP漏掉、路线内受限SEP补充找到 | 紫色 |

这些是“结构由哪些测量支持”，不是“透镜概率”或最终A/B/C等级。紫色和绿色属于不同来源，不能直接互相比较谁更可靠。

SEP共识和几何路线都来自同一份前景减除残差，因此`SEP + geometry`表示两种相关测量共同指向该结构，而不是两份统计独立证据。

## 怎样判断原始SEP与路线一致

- 使用候选像素到圆/椭圆路线的实际径向偏差；
- 以路线已经记录的搜索半宽为容许范围，不新增80%一类经验门槛；
- 同时记录连续的像素重叠比例与中位偏差，方便以后标定；
- 路线相对相邻对照区域必须具有正的S/N差；
- 由某个SEP种子拟合的路线不能单凭该种子反过来证明自己，必须还有独立的新恢复结构或另一段一致的SEP结构；
- 中心后备路线不由某个种子的形状拟合产生，因此可以为相符的原始SEP结构增加几何关系支持；但路线和SEP仍使用同一张残差图，二者相关，不能当作两个统计独立实验。

## 反证风险与结构支持分开记录

一个结构可以同时“几何上值得保留”和“前景减除风险较高”。因此以下内容只进入审计标记，不会覆盖结构支持等级：

- `near_core_subtraction_sensitive`：靠近中心，容易受前景减除影响；
- `foreground_comparison_changes_pixels`：换用PSF-MGE比较模型后，部分像素发生变化；
- `not_surviving_comparison_model`：换模型后没有像素继续超过同一门槛。

## 新增结构化输出

- `observation.json.model_candidates[].structural_support_level`：结构支持等级；
- `support_sources`：SEP共识、几何路线、路线内SEP等支持来源；
- `geometry_consistent_path_ids`：真正通过几何一致性检查的路线；
- `path_overlap_fractions`与`path_median_deviation_px`：连续关系测量；
- `candidate_system_ids`：候选属于哪些路线组合；
- `observation.json.candidate_systems`：同一路线结构的联合记录；
- NPZ新增SEP-only、SEP+geometry和route-recovered三类精确像素掩膜。

## 诊断图颜色

- 橙色：SEP看到但还没有几何支持；
- 绿色：原始SEP结构同时与合理路线一致；
- 紫色：路线内第二次SEP补充找到；
- 颜色只说明来源和结构支持类型，不是最终置信度。

## 验证结果

- 23项自动化测试全部通过；
- 新测试确认种子路线不能自我证明；
- 新测试确认中心后备路线可以为已有SEP结构增加几何关系支持；
- 指定样本`102019123_NEG567245233502945885`完整运行成功：原始大块为橙色`raw_sep_only`，环附近小结构为紫色`route_recovered`并带近中心审计标记；该样本没有满足条件的绿色结构；
- 当前仍有0个候选晋级为评分用正式结构，因此A/B/C没有被未经标定的新逻辑改变。

## 下一步

1. 用专家像素圈选样本标定结构合并、拆分与晋级；
2. 检查有绿色和紫色共同组成系统的真实案例；
3. 加入环段组合、多重像组合和颜色一致性测量；
4. 使用独立验证集确定哪些结构支持与反证组合可以进入后端证据；
5. 最后标定A/B/C映射，而不是直接把结构支持等级当作候选等级。
