# LensAgent 当前版本说明

> 当前版本：`0.13.0`
>
> Observation schema（观察文档格式）：`1.12`
>
> 本次主题：全候选信号审计与椭圆路线解耦

## 本次解决了什么

上一版候选审计把“是否具有椭圆路线支持”作为晋级条件。该方法在路线恰好覆盖真实系统的样本中可以有效压低干扰，但在复杂前景、四重像或路线范围不足的样本中，也会把已经被全图SEP稳定检出的路线外结构挡在后端之外。

本版本保留现有SEP、椭圆路线二次寻找和局部分割，同时把图4中的全部候选交给同一套信号审计：

```text
SEP与椭圆Model提出图4候选池
├─ 全图SEP、路线外
├─ 全图SEP、路线内
└─ 路线内二次SEP恢复
↓
信号真实性审计
├─ promoted：具有可用探测信号，生成structure
├─ hold_for_review：数据或处理风险过高，暂缓复核
└─ trace_only：探测事实不足，只保留追溯
↓
多假设推理、反证、决策审计与报告
```

椭圆路线仍负责补找弱结构、记录候选之间的几何关系，并在适配样本中突出重点区域；但路线内外只作为发现来源，不再决定候选能否通过信号审计。

## 信号审计检查什么

审计不增加透镜规则或新的S/N科学阈值，而是复用视觉链已有测量，分为三个区块：

- 信号质量：候选是否已经通过全图SEP或路线限制SEP，是否具有连通正残差信号；
- 处理稳健性：数据是否可用，前景精细模型是否成功，候选在PSF-MGE比较残差中是否被完全抹掉；
- 发现来源：候选来自全图SEP、全图SEP加路线一致，还是路线内二次恢复。

`geometry_used_for_verdict=false`明确表示几何路线没有参与信号审计结论。路线恢复候选会记录`search_conditioned_route_recovery`，提醒后端它是在受限搜索中发现、不能当作独立于路线的第二份证据。路线外候选会记录`geometry_route_support_absent_not_a_signal_veto`，表示缺少路线支持但这不等于信号无效。

## 三种结果怎样理解

| 结果 | 中文含义 | 是否进入`structures` | 是否等于强透镜证据 |
|---|---|---:|---:|
| `promoted` | 已有探测结果足以作为可测量残差信号 | 是 | 否 |
| `hold_for_review` | 数据或前景处理敏感性阻止自动交付 | 否 | 否 |
| `trace_only` | 缺少最基本的探测级信号事实 | 否 | 否 |

路线外但信号可靠的结构现在可以进入`structures`，后端再比较它更适合强透镜、普通星系、并合、投影还是处理伪影解释。审计本身不把任何结构命名为弧、环、多重像或透镜。

## 新增可追溯内容

`observation.json`中的每项`candidate_structure_audits`新增：

- `audit_scope=signal_reality`：审计范围只限信号真实性；
- `discovery_context`：记录全图SEP、全图SEP加路线或路线恢复来源；
- `geometry_used_for_verdict=false`：路线不作为审计门槛；
- `sections`：分别记录信号质量、处理稳健性和发现来源检查。

新增`vision_signal_audit.png`：左图展示图4全部候选池，右图独立展示信号审计后的晋级、暂缓与追溯结果。`vision_artifacts.npz`同时保存三类审计像素掩膜。

## 当前边界

- 审计不会修改、微调或重新拟合当前椭圆路线；
- 本版本没有实现Agent自动调参或自动重跑视觉流程；
- 审计只能验证已经进入图4候选池的结构，无法凭空找回SEP和软排除列表都没有记录的信号；
- 多波段颜色审计和真正独立的PSF/前景模型验证仍需后续实现；
- 路线外候选增多后，必须用专家标注样本测量召回率和误晋级率，不能把单个成功样本当作总体准确率。

## 本次验证

- 30项自动化测试全部通过；
- `102019123_NEG567245233502945885`保留11个候选：10个信号审计晋级，1个因比较前景模型完全抹除而暂缓；其中7个为路线外全图SEP来源；
- `102018668_NEG595646727509469177`保留10个候选：10个均有既有探测级信号并晋级，其中5个为路线外全图SEP来源；
- 两个样本都生成了`vision_signal_audit.png`，完整流程和后端推理运行成功；
- 这些数量只说明路线门槛已经解除。晋级结构中可能包含真实但与透镜系统无关的天体，必须由后续多假设推理解释，不能把绿色审计结果理解为“正确透镜结构”。
