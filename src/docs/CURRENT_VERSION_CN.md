# LensAgent 当前版本说明

> 当前版本：`0.7.0`
>
> Observation schema（观察文档格式）：`1.4`
>
> 本次主题：前景星系减除的双模型对照审计

## v0.7.0 更新

视觉层现在会在原有正式前景星系模型之外，再拟合一份考虑 PSF（点扩散函数，即仪器把光点模糊开的方式）的简化 MGE（多高斯展开）比较模型。它相当于用第二块不同的“橡皮擦”复核：原先测到的结构换一种擦法后还剩多少，以及两份残差图有多相似。

比较结果写入 `foreground_model_comparison`，并生成 `vision_foreground_model_comparison.png`。这张六宫格依次展示原图、当前正式模型、正式残差、PSF-MGE 比较模型、比较残差和两模型差异。

重要边界：比较模型只用于审计，`used_for_detection=false`。它不会改变正式结构检测、假设推理或最终结论，也不能单独证明一个结构是真透镜或假残差。本次只测试了三个代表样本，没有重跑既有批量结果。

## v0.6.0 回顾

v0.6.0 将视觉检测产物正式定义为“未分类残差结构”，不再在视觉层把它预先命名为弧。新 Observation 会验证输入是否符合 Zenodo v0.0.3 的 Euclid Q1 SLDE 切图契约：300×300像素，并含VIS、Y、J、H各自的FLUX、PSF和RMS扩展。

本版本新增干净的VIS arcsinh和MTF专家观察图，包含完整视场和中央100×100像素两种尺度。它只改变人看到的PNG显示，不改变FITS、残差或检测数值。v0.5.0的WCS定位能力继续保留；前景建模和结构筛选规则本次没有改动。

## 当前视觉流程

```text
FITS / PNG
→ 读取图像与噪声
→ 定位中心、屏蔽污染源
→ 拟合并减除前景星系光
→ 得到残差图和残差 S/N 图
→ S/N 多阈值稳定性检测 + SEP 多参数共识检测
→ 两路结果交集形成未分类残差结构像素
→ 测量半径、角度、切向排列、信噪比等事实
→ 写入 Observation
→ 专家推理、审计、报告
```

视觉层只回答“测量到了什么”，不会在过程图中直接宣布“是透镜”或“不是透镜”。

## 每次 analyze 新增的可追溯文件

- `vision_snr_threshold_process.png`：三行多列。第一行是每个真实 S/N 阈值的掩膜；第二行是掩膜后的残差；第三行是相邻阈值层壳和最终存活层级图。
- `vision_sep_consensus.png`：在 SEP 不同分割参数下反复出现的结构。标签显示“存活次数/总运行次数”和切向偏差。
- `vision_residual_structure_extraction.png`：依次展示星系减除残差、SEP 候选范围、低阈值 S/N 掩膜，以及二者交集产生的未分类残差结构像素。
- `vision_expert_views.png`：无圆圈、方框和结构标签的VIS arcsinh/MTF专家观察图；同时展示全视场和中央100×100像素。
- `vision_manifest.json`：记录输入文件 SHA-256 指纹、文件大小、运行参数、处理顺序和所有过程文件路径。
- `observation_summary_cn.md`：Observation 的中文解释版，包含快速概括、输入质量、模型状态、逐结构数值、整体几何、限制和结论边界。
- `vision_field_context.png`：完整VIS视场，标出诊断裁剪框、4～25像素搜索环、中心、S1/S2结构编号、N/E方向、中心RA/Dec和像素尺度。
- `vision_rgb_context.png`：自动比较RGB与FITS的方向映射；只有图像相关性通过检查时才生成，并在彩色原图上画出相同位置标记。

项目固定流程只在 [`VISION_PROCESS_FLOW_CN.md`](VISION_PROCESS_FLOW_CN.md) 中保留一份。

中文摘要不调用 LLM，同一个 Observation 会产生相同文字；它不会新增事实、评分、候选等级或透镜结论。JSON 仍是正式机器记录，中文摘要只负责帮助人工阅读。

## WCS测量

Observation 1.2 新增 `astrometry`，记录WCS可用性、ICRS投影、像素尺度、中心RA/Dec、N/E像素方向、显示原点和是否重投影。每个结构新增RA、Dec、角秒半径和天空位置角；切向偏差在WCS可用时按天空坐标重新计算。

本版本会读取所选波段的PSF图像并保存在NPZ中。正式检测仍沿用原前景模型；新增的PSF卷积MGE只是一份比较审计模型，不能把“比较模型考虑了PSF”理解为“正式检测已经完成了PSF校正”。

## 验证

- 自动化测试：14项通过；
- 三个真实Euclid Q1 FITS均通过12扩展、300×300输入契约检查；
- 三个样本的结构数量与v0.5.0一致，证明本步没有改变检测规则；
- 问题样本WCS：有效，像素尺度0.1角秒/像素；
- 中心坐标：RA 56.724524°，Dec -50.294625°；
- 方向：北向上、东向左；
- RGB/FITS自动匹配：纵向翻转映射，相关系数0.947；
- FITS和PNG端到端视觉处理均通过。

原有文件继续保留：

- `vision_diagnostic.png`：输入、模型、残差和最终掩膜的四宫格总览；
- `vision_artifacts.npz`：供程序或科研复核读取的完整数值数组；
- `observation.json`：视觉层的结构化测量事实；
- `reasoning.json`、`summary.json`、`report.md`：推理、审计和最终报告。

`report.md` 现在会列出上述视觉追溯文件路径，使用者无需再猜哪个二进制文件对应什么内容。

## 与 `.tmp` 后期两行四列图的关系

`.tmp` 后期的两行四列图确实是过程图：它展示星系减除后的残差如何在多个 S/N 阈值下被筛选。当前版本沿用同一类思想，并稍作扩展为三行：除了阈值掩膜和掩膜残差，还保存相邻阈值之间消失的像素及最终存活层级。

当前正式管线使用的是“前景星系减除后的原始残差 S/N”通道，没有使用早期 `.tmp` 示例里的小波去噪。因此清单明确记录 `wavelet_denoising_applied: false`，避免把两种处理方法混淆。

## 需要正确理解的边界

- PNG 图用于人看和审计；NPZ 数组仍是精确数值证据。
- S/N 多阈值和 SEP 共识共享同一张残差图，因此不是两份完全独立的证据。
- 本次升级提高的是可解释性和可追溯性，不代表准确率已经提高。
- 最终分数仍是内部推理评分，不是经过数据集标定的透镜概率。
