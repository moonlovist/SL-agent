# v0.28.0 人工前景后的拟合质量与掩膜一致性

本版修复 human-in-the-loop 改换前景目标后仍沿用旧目标 `source_mask`/`fit_mask` 的状态错误。人工中心、拟合掩膜、外部污染源掩膜及后续残差搜索现在处于同一原生像素坐标系；旧掩膜不会再把新目标周围的弧结构遮掉。

第 2 层定义收紧为保守的高表面亮度核心种子，不代表完整前景外缘，也不直接等于减除区域。自动按钮取所选 SEP 对象的中心二阶矩椭圆核心，不再复制整个低阈值分割岛；人工点保持原位，接受后只在其附近最多 3 像素内按亮核做确定性精调。记录同时保存人工位置、精调位置和位移。

连续径向极小值仍优先定义前景/源边界。若人工样本没有形成连续、半径一致的极小值，不再让中心拟合区全部开放；改用人工核心的第 90 百分位椭圆半径加远处天空，中间不确定环带从前景拟合中排除。明确的第 3 层源像掩膜继续硬排除。

MGE与双 Sérsic 的加性天空项由远处、源掩膜后的像素约束，只允许在局部噪声尺度内变化。模型选择除留出角区残差尺度外，新增背景残差中位数、背景稳健尺度、宽环残差中位数和核心 180 度反射差异。背景整体偏移超过一个输入噪声单位、背景尺度严重异常或宽环存在大范围偏置的模型不能通过质量门。

若所有模型均不合格，`model_success=False`、`data_quality.usable=False`，S/N/SEP/几何候选检测不启动，专家层必须弃权而不是输出非透镜 X。若模型整体合格但核心仍呈明显红蓝偶极或正负强残差，触及核心的候选进入 `foreground_contaminated` 复核通道；远离核心且具有多模型、信号和几何支持的结构不受该隔离影响。该规则不是中心禁区，不会按位置直接删除近核像或径向弧。

0528回归复用了用户保存的同一份人工标注。修复前旧掩膜覆盖新目标搜索环境，候选数为0并错误输出X；修复后背景残差接近零，恢复4个核心外结构，其中两条主要结构具有切向形态，唯一正式结果恢复为A。此结果验证的是状态与拟合链修复，不是调整A/B评分阈值。
