# v0.21 确定性、可追溯实验版

## 定位与自查

目标是复现专家的强透镜视觉分级，不是证明每个目标的物理身份。本版仍是确定性像素算法＋透明规则，不使用多模态、外部模型 API 或生成式补弧。此前“必须接多模态才能实现视觉判断”的建议不成立；但确定性规则也不等于已经达到人类专家能力。可复现与科学准确性必须分别验证。

## 每一步实际做什么

1. 读取 FITS 指定波段、RMS、PSF/WCS；保留原像素和输入文件指纹。
2. 运行既有前景拟合、SEP 和几何路线搜索，保存实际检测像素掩膜；不填补没有观测信号的弧。
3. 对每个候选掩膜统一重测：通量、对角 RMS 孔径误差、质心、像素中位半径、角度占有、局部方向、核区像素重叠，以及另一残差中同一孔径的有符号通量。记录掩膜 SHA256。
4. 在评级前合并证据。以既有最小 5 像素、名义 SNR≥4、正通量条件识别可测候选；这些是未标定的检测启发式，不是透镜物理定律。缺测、低信号、完全重复掩膜逐项记录，不能静默丢弃。旧来源标签不作否决条件。旧正式结构被对应候选的新测量替换一次，不重复投票。不同但部分重叠的掩膜尚未完成系统级合并验证。
5. 从合并后的结构重算场景角度占有等统计；缺少全部像素角度记录则标为不可用，不拿旧场景统计代替新结构统计。
6. 原有构型解释器只裁决一次，输出证据、疑点和命中的布尔条件；取消候选补充规则以及“取两次较高等级”。
7. 审计从未修改的源 Observation 重放并比较整个证据档案、标准化输入和评级。重放验证实现一致性，不是独立科学确认。
8. 发布 A/B/C/unknown。审计失败发布 unknown；内部 X 保留原因 non_lens_vote_X，与数据不足区分。命令遇审计失败返回 2。内部 proposed vote 不能替代 published_grade。

## 本版科学语义修正

- near_core 使用实际掩膜像素与既有 6.5 px 核区的重叠，质心半径继续保存但不用于污染推断；核区大小仍是待验证的工程尺度。
- 长弧/环可用局部切向测量，环形候选不再要求至少两个提取块；单纯大跨度不等于环。径向兼容性比较使用像素中位半径。
- 比较超阈值比例不是通量保留率。稳健性改查同一孔径的有符号名义 SNR，复用既有检测下限 4，未按这批目标调阈值。低占有率不判污染；缺少新的孔径测量就是未测得，历史 JSON 若不重测像素可能更保守。
- 相关结构在比较残差中均有显著负孔径通量时输出处理冲突 unknown，不擅自判伪影。
- 附近多亮块不是已证实多核，更不是能解释弧的并合证据；只记需要检查的问题。
- 旧模型失败、路线来源仅记录不确定性。没有真正执行的删除证据检验写 not_tested。
- 所有 agent 数字专家分保持空，不制造十位专家的汇总分。Q1 Engine A §8.3 的目录 C 切分修正为 1 < score ≤ 1.5，仅供未来标定后的聚合分使用。

## 可追溯文件

- source_observation.json / observation.json：源测量。
- reasoning_observation.json：真正进入判断的合并后结构；原文件不变。
- summary.json：published_grade、publication_reason、证据合并逐项记录、参数、全部关键条件及证据引用。
- report.md：阅读版证据与合并表。
- vision_artifacts.npz / segmentation FITS：实际像素来源；具体名称见 artifacts。
- run_manifest.json：输入与像素数组指纹、源代码文件指纹、参数、Python/依赖/平台、数值线程环境。
- code_snapshot：运行时源代码副本。只有代码指纹并不足以重现，因此同时保留源码和依赖版本。

同一环境、同一保存测量的重复判断应完全一致。跨机器浮点库或依赖变化不承诺逐位相同；必须对照像素测量差异和分级差异验证。

## 尚未解决，不能夸大

这是修正语义和证据流的试验，不是通过盲测的科学升级：SNR 未含相关噪声、前景拟合误差与搜索试验；多波段颜色和 PSF 伪影诊断未接入评级；环形局部方向仍有像素/角度门槛；fold/cusp、内连通/不对称等旧构型代理仍需物理与阴性样本验证；PNG 的科学测量能力有限。简化模型成功不能证明透镜，失败也不能证伪。B/C 边界、A 的纯度及 unknown 的覆盖率必须做独立 Q1 标注盲测。

既往讨论过的 A/B 样本属于开发回归集，不是独立测试集；以文件夹标签作此次对照，尚未重新交叉核对官方目录逐目标标签。不能用“A 更多了”作为成功判据。

## 科学参考

- [Euclid Q1 Discovery Engine A §6、§8.3](https://arxiv.org/html/2503.15324v1)：视觉类别与多专家汇总目录不是同一量。
- [强引力透镜物理综述](https://link.springer.com/article/10.1007/s11214-024-01041-w)：弧、环与多像不由分割块数或精确等半径定义。
- [He 等 2024](https://arxiv.org/abs/2403.16253)：透镜前景光的形态复杂性与建模系统误差。
- [STScI 相关噪声说明](https://hst-docs.stsci.edu/drizzpac/chapter-3-description-of-the-drizzle-algorithm/3-3-weight-maps-and-correlated-noise)：逐像素 RMS 不足以涵盖重采样图像的孔径噪声；不能直接照搬 HST 系数到 Euclid。
