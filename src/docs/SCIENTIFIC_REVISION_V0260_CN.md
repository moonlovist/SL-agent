# v0.26.0 连续极小值边界与前景光约束

本版删除旧的分角向扇形软权重。旧方法只会在少数角度从局部极小值向外降低权重，不能构成前景与源像之间的闭合边界，在实际样本中常为零个或孤立扇形，作用很小。

## 新边界

程序沿前景星系的椭圆坐标采样 72 条径向亮度曲线。一个候选极小值必须同时满足：内侧前景光比谷底亮、外侧存在再次增亮，并达到局部 RMS 对应的最低反差；相邻角度的谷底还必须连续且半径相容。孤立谷底直接舍弃。

若存在受支持的连续角段，程序用其谷底半径中位数和前景内区的轴比、位置角建立一个闭合椭圆。拟合只使用椭圆内部与远处天空；边界外到远天空之间的歧义环带完全不参与前景拟合。若没有可信的双侧极小值，则不臆造边界，拟合包含图像中的正常可用像素。

这不是说透镜源一定是完整环，也不是把椭圆边界当作透镜证据。它只把局部观测到的“前景下降—谷底—外部再次增亮”转换成前景拟合的保守排除区。

## 防止粘连弧牵引前景模型

SEP 有时会把前景盘和单侧弧分在同一个连通块内。因此不能把整个中心连通块都当作确定的前景光。本版只用中心核以及相对选定中心约 180 度成对出现的连通块像素约束外层前景几何和稳健拟合。中心对称性在这里只是普通星系光的一阶建模先验，不参与透镜评级；不成对的单侧结构仍可被稳健拟合剔除并留在残差中。

## 审计输出

`vision_source_boundary.png` 同时显示输入与闭合边界、二值拟合纳入图、最终前景模型和减除后的残差信噪比。`observation.json` 记录候选极小值数、连续支持角度、边界半径、轴比、位置角、极小值反差以及是否成功建立边界。

本版不修改后续 A/B/C/X 评分阈值。前景减除改变了实际候选像素时，最终类别可以随测量证据变化；这种变化必须通过残差和候选审计解释，不能用已知标签强行固定。
