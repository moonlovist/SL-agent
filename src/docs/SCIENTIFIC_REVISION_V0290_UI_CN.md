# v0.29.0 桌面工作流与人工屏蔽层

本版新增完整桌面工作流，不改变既有前景模型、结构检测、颜色证据或 A/B/C/X 裁决规则。

## 主界面

运行 `lens-agent ui` 后可以导入单个 FITS 或文件夹。样本由独立后台进程顺序执行，主界面保持响应；完成后按照 A、B、C、X、无法判断、运行中、等待运行和运行失败分组。结果详情直接读取 `observation.json`、`summary.json` 与其中记录的诊断图路径。

每次自动运行和人工重跑写入独立版本目录。UI 的 `lensagent_ui_state.json` 只保存路径、状态和历史索引，不替代科学 JSON/FITS 产物。等级始终标为单 Agent 暂定类别，不生成概率或伪置信度。

## 人工闭环

“人工校正”在独立进程中打开原生像素编辑器。接受标注后完整重跑；主界面可以继续浏览其他对象，完成后发送桌面提醒。前景失败不会自动弹窗，只会在列表中留下质量状态和复核提示。

人工掩膜现在有三个不同的科学角色：

1. `FOREGROUND`：可信前景核心，用于中心与模型初始化；
2. `FITEXCL`：arc、环和源像保护区，不参与前景拟合，但仍可进入残差检测；
3. `ANALYSIS_EXCLUDE`：亮星、边缘干扰源、坏区域等无关区域，不参与拟合、检测、天空估计或颜色孔径。

`ANALYSIS_EXCLUDE` 不删除原始像素，也不得把掩膜内的非检测解释为反对透镜的证据。旧版 v1 人工标注仍可读取；缺少该层时按全零处理。新版写出 v2 JSON 和同名 FITS HDU。

## 主题

主界面与标注器支持日间和夜间模式。黑/白为背景基础色，交互色主要采用 `#337BAC`、`#71b0fd`、`#4FB1B2`、`#A9D9BB`，`#fdc0e1` 仅用于警告或人工屏蔽提示。
