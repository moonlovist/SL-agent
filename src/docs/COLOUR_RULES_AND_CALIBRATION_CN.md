# 强透镜颜色证据规则与标定数据规范

## 1. 规则目标

颜色不是独立的透镜分类器。它检验两个不同问题：

1. 被某个透镜构型假设为多重像的结构，是否与同一背景源的消色差成像相容；
2. 候选结构能否与前景星系光区分。

第一个问题是直接的同源关系检验。第二个问题只反映区分能力：候选与前景颜色相似可能来自前景污染、真实相似SED或错误前景模型，不能单独否定透镜。

## 2. 当前可执行规则

### 测量质量门

- VIS保持原始形态分辨率；颜色测量使用共同PSF近似匹配图像。
- 波段必须有FLUX、RMS、PSF、MAGZERO和相容WCS。
- 单候选单波段默认要求正通量且S/N不低于3。
- 每个候选波段默认至少需要4个旋转局部控制孔径。
- 两个SED默认至少需要3个共同可靠波段。
- 候选孔径重叠超过较小孔径的20%，该候选对颜色记为unknown。
- 候选孔径与前景核心重叠超过候选孔径的15%，候选—前景关系记为unknown。

这些值是可追溯的暂定测量质量界限，不是Euclid Q1的A/B/C分界。

### 同源颜色关系

比较两个候选在各波段的星等差，并拟合一个与波段无关的亮度偏移。该偏移允许不同透镜放大率；剩余的非灰度差才是颜色差。

- `consistent_with_achromatic_scaling`：最大非灰度差不超过0.20 mag，且约化卡方不超过2；
- `strongly_inconsistent`：最大非灰度差至少0.35 mag，且至少达到3 sigma；
- `inconclusive`：介于两者之间；
- `unknown`：波段、信噪比、局部控制或孔径独立性不足。

每个波段的星等差、含系统误差的误差、相对最佳灰度偏移的残差和显著度都会保存。0.10 mag系统误差底限也随输出保存，后续必须用标注样本和注入实验校准。

此外另行保存一个**不参与当前评级**的通量域诊断：直接拟合 `F1 = alpha * F2`，输出最佳 `alpha`、`same_sed_flux_chi2`、自由度及逐波段残差。这个诊断保留有限的低S/N和负通量，不会因为星等无定义而丢失信息；在原生协方差和前景模型误差尚未完整传播前，它只用于Q1标定。

### 构型门控

全量候选颜色仍会测量并保存，但只有被一个实际支持的透镜构型连接的“跨结构候选对”可以参与评级。当前构型包括共同中心/环、fold、cusp、径向—切向组合和紧致多像。

同一分割结构内部的碎片不会因为两两颜色差而否定整个系统；没有被构型连接的邻源、残差或其他候选也不能投反对票。

### 多像组颜色统一性

逐像对一致不等于整个多像系统一致。Agent把同一几何构型中的独立像视为一个颜色关系网络：候选像是节点，达到质量门且颜色一致的像对是连边。

- 双像系统需要一条高可信一致连边；
- 三像系统至少需要两条高可信一致连边并连接全部三像；
- 四像系统至少需要三条高可信一致连边并连接全部四像；
- 不要求所有可能像对都可测，只要求形成覆盖全部必要像的连通网络；
- 若连通必须依赖中等可信颜色，只记为部分支持；
- 不同背景源分别建组，同一物理弧的分割碎片先合并，不能充当独立像。

组级状态为：

- `group_consistent`：高可信一致网络覆盖全部必要像，且没有高可信冲突；
- `group_partially_consistent`：仅覆盖部分必要像，或完整连接依赖中等可信证据；
- `group_colour_tension`：构型关联像对达到测量质量门，但颜色既不满足一致条件，也未达到强冲突；
- `group_mixed`：同组同时存在高可信一致和高可信冲突；
- `group_conflict`：同组存在高可信冲突而没有高可信一致支持；
- `group_unknown`：没有足够的可靠颜色关系。

只有 `group_consistent` 才称为“整个多像组颜色统一”。`group_partially_consistent` 是辅助支持，不能被表述成全组一致；`group_unknown` 不降级。`group_colour_tension` 可解释一个构型仍需保留在B，但不能单独把几何上独立可靠的A降级，也不能证明两个结构必然不同源。`group_mixed` 或 `group_conflict` 中的高可信冲突可以限制A，但不能单靠颜色自动判为C。

## 3. A/B/C/unknown语义

### A

- 清晰透镜形态仍是必要基础；
- 构型关联多像颜色一致可增强同源解释；
- 构型必需像之间出现可靠、无法解释的强颜色冲突时，当前将A限制为B；
- 颜色不可测不能单独把强形态从A降级。

### B

- 形态很可能是透镜但仍需确认时保持B；
- 颜色一致不能把不完整形态单独提升为A；
- 清晰形态存在构型关联颜色冲突时可由A限制为B；
- 候选与前景颜色相似只增加歧义，不单独规定B。

### C

- C要求透镜样形态与普通星系、并合、投影或伪影解释仍有实质竞争；
- 颜色冲突可以支持这种歧义，但当前没有C标定集，尚不实施“某一颜色阈值自动把B降成C”；
- 后续应检验：当一个多像构型所需的全部高质量配对均冲突、且没有独立单弧/环证据时，是否能稳定区分B与C。

### unknown

- `colour evidence = unknown`只表示颜色信息不可用；
- 它不等于对象总等级unknown；
- 对象总等级unknown仍由整体数据不可用或决策审计失败产生；
- 未来只有标定证明关键颜色信息缺失会使当前图像完全不可判断时，才能讨论颜色触发总unknown。

## 4. 批量运行必须保留的数据

运行LensAgent后，使用：

```powershell
python scripts/export_colour_rule_dataset.py `
  --dataset "A=你的A输出目录" `
  --dataset "B=你的B输出目录" `
  --dataset "C=你的C输出目录" `
  --dataset "X=你的非透镜控制目录" `
  --dataset "unknown=你的不可判定输出目录" `
  --output "颜色标定输出目录"
```

当前没有C或X目录时可以省略相应参数；导出格式不变，之后直接追加批次重跑导出。`X/non-lens`表示专家认为不是透镜，`unknown`表示数据或证据不足以判定，两者不得合并。

### `colour_objects.csv`

每个对象一行，至少包含：已知标签、Agent等级、审计状态、可用波段、颜色证据状态、全量候选对数量、构型关联对数量、各状态计数、是否限制A、是否提供支持、前景歧义、最大颜色差和显著度、PSF宽度、局部控制数量及输入哈希。

### `colour_component_pairs.csv`

每个候选对一行，包含：是否被透镜构型关联、构型编号、关系状态、可用波段、灰度亮度偏移、最大非灰度差、最大显著度、星等域卡方、自由度、约化卡方、孔径重叠、逐波段残差和显著度；另含不参与评级的通量域最佳亮度比例、同源SED卡方及逐波段残差。

### `colour_candidate_vs_foreground.csv`

每个候选—前景关系一行，包含：可区分/不可区分/不确定/未知、颜色差、显著度、核心重叠和逐波段诊断。该表用于研究前景污染，不直接作为硬等级门槛。

### `colour_apertures_by_band.csv`

每个候选每个波段一行，包含：前景减除后及原始孔径通量、误差、S/N、星等、两种归一化通量、局部控制散布、控制数量、孔径面积和掩膜哈希。这张表用于判断错误来自真实异色，还是来自低S/N、前景减除或孔径定义。

## 5. 标定时必须回答的问题

1. A、B、C、X/non-lens中可测颜色的比例是否相同；不能只在高S/N对象上比较正确率，也不能把unknown当作非透镜负样本。
2. 构型关联颜色一致率能否区分A/B/C，而不是全量任意候选对一致率。
3. 颜色冲突在控制前景核心重叠、局部散布和PSF后是否仍存在。
4. 一个强冲突是否足够，还是需要同一构型中多个独立颜色或多个配对共同冲突。
5. 前景颜色相似是否只有与盘形态、核心混光或减除敏感性联合时才有区分力。
6. 阈值在留出对象、不同信噪比和不同弧半径区间是否稳定。
7. C样本加入前，不允许把A/B开发样本上最优的数值直接命名为B/C边界。

## 6. 当前限制

- 高斯二阶矩只近似匹配PSF宽度；
- 尚未传播完整前景模型不确定度和原生协方差；
- 积分颜色可能受源内颜色梯度和差分放大影响；
- 类星体还可能受时延、本征变化和微透镜影响；
- 没有源平面对应区域时，颜色一致性仍只是图像平面近似；
- 当前颜色规则是可审计的开发规则，不是已完成Q1标定的概率模型。
