# v0.24.0 目标选择与前景减光修订

本版把“选哪个对象”和“如何减去它的前景光”明确分成两个阶段。

## 单目标路由

全场 SEP 检测后，程序只将面积和信噪足以检查的对象缩减为最多四个候选。面积、
亮度只用于形成短名单；最终路由比较原图中候选周围的径向轮廓偏离、角向覆盖和
多片段代理量，并只把切图中心作为弱先验。程序始终确定性地选出一个对象并结束
路由，不为其余候选生成独立报告。所有路由量均标为 `routing_only`，不进入后续
透镜评分或证据表。显式 `--center-x/--center-y` 仍优先。

这些像素形态只能说明某对象更值得按候选系统继续处理，不能证明它是透镜，也不能
替代红移、颜色或质量模型。

## 软源光保护

对选定中心，以 PSF 尺度平滑后的扇区径向亮度曲线寻找“先降后升”且深度超过局部
RMS 的极小值。只在确有极小值的角向，从该位置向外降低拟合权重；没有可靠极小值
的方向保持原权重。因此算法不假设完整圆环，也不把一个硬圆以内全部当成前景。

## 前景模型库

同一曝光上比较四个模型候选：双几何 PSF 卷积 MGE、共享亚像素中心的有界双 Sérsic、
平滑等光度线模型和固定几何 PSF-MGE 回退。MGE 振幅非负，使用输入 RMS 加权和稳健
剪裁；双几何允许内外轴比和位置角不同。模型以留出的角向扇区残差、中心残差惩罚和
复杂度惩罚确定一个主模型。其余模型仅作为同曝光敏感性审计，不能称为独立证据。

最终仍只输出一张主残差、一份 Observation 和一份专家结果。目标路由始终记录在
Observation 与 manifest 中；只有分数接近、中心先验冲突或人工覆盖时才额外输出
`vision_target_selection.png`。`vision_source_boundary.png` 记录软权重；`vision_artifacts.npz` 保存
`source_protection_weight`；完整模型库选择记录在 `supplementary_diagnostics` 与 manifest。

## 科学边界

这仍不是同时拟合透镜光、透镜质量和源光的前向贝叶斯模型。单波段形态路由可能受
伴星、旋臂、潮汐结构和 PSF 残差影响；软保护也不能保证所有弧光都不被吸收。因此
比较模型存活率继续作为系统误差审计，结果保持试验性且未作目录级校准。
