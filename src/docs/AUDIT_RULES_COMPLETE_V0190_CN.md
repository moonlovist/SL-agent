# LensAgent v0.19.0：审计流程与规则完整清单

核对日期：2026-09-03。依据当前本地实际代码，观察记录格式 1.15。

本文提取现有行为，不修改算法，不把拟议方案当成已实现功能。正文以默认 FITS 输入为准；PNG 差异在第十一节。
所有百分比、角度和像素门槛均是当前程序的工程规则，不是已经验证适用于所有透镜的物理定律，也不是论文专家打分阈值。

## 阅读约定

- **全部满足**就是“且”；**任意一个满足**就是“或”。
- `≥` 包含等号；`>` 不包含等号。文中保留实际边界，不使用“大约”代替。
- **候选 C1/C2**是视觉层发现的区域；**结构 S1/S2**是通过结构审计、交给评级层的区域。这里的 C1 不是 C 级。
- **信噪比**：信号相对于噪声的大小。数值越大，通常越容易从噪声里辨认，但不代表越像透镜。
- **残差**：原图减掉估计的前景星系光后剩下的图。
- **独立比较模型**：使用另一种前景光模型再次减除，看看同一片像素是否仍显著为正。
- **正式结构**也只是可靠程度足够的可测区域，并不自动等于真实透镜像。

## 一、完整流程：到底有几道审核？

```text
输入 FITS/PNG
  ↓
读取图像和噪声 → 选择目标中心 → 拟合并减除前景光
  ↓
多阈值检测 + SEP 多参数检测 + 圆/椭圆路线补找
  ↓
第一道：候选结构审计
  ├─ 正式结构：主要候选 / 晋级恢复候选 → 测量几何等特征
  ├─ 待复核：保留候选事实，不能当作正式结构
  ├─ 前景污染：隔离，保留记录
  └─ 追溯线索：保留记录
  ↓
观察记录 Observation：正式结构 + 候选审计记录 + 测量 + 风险
  ↓
第二道：专家评级
  先查数据可用 → 信号可信 → 构型是否成立 → 有无强替代解释
  按固定顺序选择：信息不足 / A / B / C / X
  ↓
第三道：判决审计
  检查引用、重复证据、遗漏解释、答案泄漏和结论一致性
  ↓
写报告：类别 + 审计是否通过 + 要求修正的问题
```

按科学关卡数是三道；名称明确含“审计”的是第一道和第三道。中间的专家评级也是规则程序。

实际专家工作流只依次运行 `ExpertAssessmentAgent`（专家判断）、`DecisionAudit`（判决审计）、
`ReportWriter`（写报告），不是多个专家投票。

**没有自动“退回视觉层 → 再提结构 → 再评级”的循环。** 主前景拟合失败时存在一次径向模型回退；
路线搜索存在预设候选枚举；这些不是因为评级没到 A 才触发的重试。
最后审计即使发现问题，目前也只是保存问题和失败标记，仍继续写出原评级；并未实现自动纠正或阻止报告发布。
因此要同时查看“评级”和“判决审计是否通过”。

代码：[工作流](../expert_agent/core/workflow.py)、[报告输出](../expert_agent/agents/report_writer.py)。

## 二、入口：图像和前景中心的硬门槛

### 2.1 图像数据

| 检查 | 当前实际规则 | 不满足的后果 |
| --- | --- | --- |
| 数组格式 | 图像必须是二维，噪声图与图像形状一致 | 报错，无法正常分析 |
| 至少有数据 | 至少 1 个像素的图像值和噪声值都为有限数 | 否则报错 |
| 有效像素比例 | 完整视觉链要求 **>99%** | 标为不可用，候选不能正式交接，专家弃权 |
| 背景噪声 | **>0** | 同上 |
| 残差背景噪声 | 专家层另要求 **>0** | 专家弃权 |
| 中心状态 | 必须没有“前景中心有歧义”标记 | 有歧义则弃权 |

有效比例的分母是全图像素数；分子是图像值和原噪声值同时为有限数的像素数。有限不等于“好天体信号”，
也不等于噪声值为正。无效图像值会替换，非正/无效噪声会补值，但有效比例是在补值前计算的。

边界细节：专家层单独写的是 **≥99%**，但还要求观察记录已标记可用；完整跑图上游写的是 **>99%**。
所以完整跑图恰好 99% 不通过。只读取外部观察记录时，结果可能取决于该记录的可用标记。

这里的噪声大于零是“分母可用”的完整性检查，不是“图像噪声越大越好”。残差稳健噪声使用
1.4826 × 绝对偏差中位数；该量为零时回退到标准差。

### 2.2 前景中心如何选

默认目标参考点是切图中心，也可以同时指定横纵像素坐标。

1. 参考点必须有限且在图像范围内，否则报错。
2. 从初次 SEP 检测对象中选“质心离参考点最近”的对象，不按亮度选对象。
3. 在该对象所属像素中，仅保留距离参考点 **≤10 像素**的部分，再取其中最亮像素作为中心。
4. 以下任意一种情况标为中心有歧义或未解决：
   - 没有检测对象；
   - 最近对象质心离参考点 **>10 像素**；
   - 第 3 步没有合格像素；
   - 次近对象距离减最近对象距离 **<2 像素**。

注意最后一条比较的是“两个对象分别到参考点的距离差”，不是两个对象彼此的间距。
有歧义时前景可靠性上限为 0.25，同时弃权；不能只看坐标非空就认为中心可靠。

10/2 像素规则依赖目标居中的切图习惯，不是星系身份识别器。

代码：[中心与预处理](../expert_agent/vision/preprocess.py)、[可用性与测量](../expert_agent/vision/pipeline.py)。

## 三、进入结构审计之前：哪些区域有机会成为候选？

这些是**上游提取门槛**。它们不直接定 A，但会决定后端有没有结构可用，不能省略。

### 3.1 默认 FITS 搜索与检测

| 项目 | 默认条件/数值 | 作用 |
| --- | --- | --- |
| 主要搜索半径 | **4<r<25 像素** | 主检测与多阈值掩膜范围 |
| 路线补找范围 | **4≤r≤25 像素** | 边界包含等号，与上项略不同 |
| 初次前景源检测 | 1.5 倍输入噪声 | 用于找前景、邻源和分割 |
| 残差 SEP 检测 | 2.0 倍输入噪声、检测最小面积 5 像素 | 找残差对象 |
| SEP 参数组合 | 3×4＝12 组 | 分裂层数 16/32/64；分裂对比参数 0.01/0.00215/0.00046/0.0001 |
| 全局 SEP 种子稳定性 | 至少 **8/12 次**检出 | 才成为内部几何种子；不是最终 A 门槛 |
| 种子像素保留 | 有限、未屏蔽、单像素残差信噪比 **≥2** | 只保留达到阈值的真实像素 |
| 种子/分割碎片最小面积 | **≥3 像素** | 少于 3 的碎片不生成结构候选 |
| 多信噪比阈值 | **2、2.58、3.34、4.31、5.57、7.19、9.29、12** | 共 8 层，后续用于稳定性审计 |
| 单层算存活 | 候选与该阈值掩膜交集的最大连通块 **≥3 像素** | 不是只要有 1 个亮点就算存活 |
| 候选多层稳定 | 至少 **3/8 层**存活 | 正式交接的稳定性门槛 |

全局 SEP 的同源归并按像素区域膨胀 1 次后是否重叠；不是按 3 像素距离归并。
配置中的 **3 像素聚类距离**用于多阈值检测的追溯对象聚类，不能混成上述 SEP 归并规则。

前景拟合时，其他对象的分割掩膜膨胀 3 次后被遮挡；残差检测时只屏蔽中心距离超过 25 像素的外部源，
相应掩膜也膨胀 3 次。两种掩膜用途不同，不能理解成把所有非中央天体从检测图删除。

### 3.2 圆/椭圆路线到底按什么筛选

路线是“建议去哪里找”，不是给缺失的环补画像素。

| 路线设置 | 实际值/规则 |
| --- | --- |
| 圆心偏移网格 | 横纵分别 −2、−1、0、1、2 像素，共 25 个圆心 |
| 椭圆短长轴比 | 0.9、0.8、0.7；圆对应 1.0 |
| 椭圆方向 | 0°、30°、60°、90°、120°、150° |
| 椭圆中心 | 当前固定在测得的前景中心，不与全部偏移网格组合 |
| 路线半宽 | max(1.5 像素、点扩散宽度估计、种子径向散布) |
| 种子散布 | 1.4826 × 种子椭圆半径绝对偏差中位数 |
| 无种子扫描半径 | 默认 6、7、…、23 像素，步长 1 |
| 保留路线数 | 最多 5 条；有种子时最多先取 2 条种子路线，余位留给中心扫描路线 |
| 路线测量可用 | 路线上有效像素至少 36，72 个角格中至少 24 格有数据 |
| 邻近对照带 | 相对路线半径内外移动 2.5×路线半宽；比较两侧背景 |
| 路线相对增强 | 路线上信噪比中位数 − 对照带信噪比中位数 **>0**，才给全局种子提供路线支持 |

路线去重：圆心距离 <1 像素、半径差 <1.5 像素、轴比差 <0.06、方向差 <15° 四项同时满足，
默认视为重复。种子候选按径向拟合误差排序，中心扫描按路线与邻带的对比排序。

对全局 SEP 种子做局部分割时：

- 候选与路线相交的连通块至少 3 像素，才可作为路线支持部分。
- 如果路线由该种子自身拟合出来，必须还有另一条原始结构或路线补找结构，才允许该路线支持它自身。
- 路线外剩余部分不会因“无路线”直接删除；满足面积要求后仍进入候选审计。

路线内补找：排除既有结构膨胀 1 次后的区域，限定搜索环带、路线和非屏蔽区，再运行 SEP。
SEP 最小检测面积 5，筛选后保留像素 ≥3，像素信噪比 ≥2；分裂层数 32、对比参数 0.005。
同一像素不能在后续路线中重复作为“新恢复像素”。

两个容易误解的实现细节：

1. `path_pixel_consistency`（像素与路线一致性）会记录“径向偏离中位数 ≤路线半宽”。但当前全局候选的
   路线交接标签主要来自上述局部相交分割，不是另设一个“重叠比例必须超过多少”的百分比门槛。
2. 路线补找产生的候选直接记录该路线关系；目前没有在这个交接标签处再要求路线对比 >0。
   它仍必须通过之后的信号审计，不能因此直接晋级。

代码：[检测与路线](../expert_agent/vision/detectors.py)、[候选组装](../expert_agent/vision/pipeline.py)。

## 四、第一道：候选结构审计的完整分支

### 4.1 每个候选先得到哪些判断

| 判断项 | 精确规则 |
| --- | --- |
| 有检测支持 | 全局 SEP 种子且 SEP 存活比例 >0；**或**路线恢复候选且记录了路线内 SEP 检出来源 |
| 有像素信号 | 像素数 >0；这里没有再次检验连通拓扑，连通性主要依赖上游分割 |
| 总信号为正 | 综合信噪比 >0；没有另设“总信噪比必须 10/20”的审计硬门槛 |
| 多阈值信息可用 | 存活次数、总次数均非空，且总次数 >0 |
| 多阈值稳定 | 信息可用且存活次数 ≥3，PNG 是 ≥2 |
| 比较模型未完全擦除 | 比较存活比例 >0；为空是未知；等于 0 才是完全擦除 |
| 贴近减除核心 | 候选被标记近核心，**或**任意候选像素落在核心区，即核心重叠比例 >0 |
| 有几何路线 | 至少一条被记录为一致的路线 |

综合信噪比在候选组装中按“候选内各像素信噪比求和 / √像素数”计算。
多阈值存活比例是次数/总次数；默认 3/8＝37.5%，它和独立模型的 75% 不是一个量。

### 4.2 按顺序执行，先命中哪条就用哪条

| 顺序 | 条件 | 结果 | 会成为 S 结构吗？ |
| --- | --- | --- | --- |
| 1 | 图像不可用 | 待复核、追溯类 | 否 |
| 2 | 检测支持/像素存在/总信号为正，任意一项失败 | 仅追溯 | 否 |
| 3 | 比较模型存活比例 **=0** | 前景污染类、隔离待复核 | 否 |
| 4 | 多阈值稳定，且有路线 | 主要候选、正式晋级 | 是 |
| 5 | 多阈值稳定，但无路线 | 恢复候选、正式晋级 | 是 |
| 6 | 多阈值不稳定或未知，但有路线 | 恢复候选、待复核 | 否，但相关候选事实可被后端读取 |
| 7 | 多阈值不稳定或未知，且无路线 | 仅追溯 | 否 |

**第一道并不要求比较存活 ≥50% 或 ≥75%。** 哪怕只有少量像素存活，只要不是零，就不会仅因此标红。
比较模型不可用也不会直接阻止稳定候选晋级；会留下风险。主模型失败、贴近核心都不是这里的单独删除条件。
几何路线改变主要/恢复交接身份，但不能代替信号稳定性。

代码：[完整结构审计函数](../expert_agent/vision/structure_audit.py)。

## 五、评级前必须分清的量：百分比、半径和角度

### 5.1 两种“半径相近”，不是同一个条件

**整组结构半径一致性：**

`半径变异系数 = 所有正式结构的像素中位半径的标准差 / 这些半径的平均值`

正式结构至少 2 条，且系数 **≤0.30（30%）**，才算整组半径相近。标准差使用总体标准差。
例如半径 8 和 12，均值 10、标准差 2，系数 20%，通过。

**折叠/尖点构型中的两两半径相容：**

`两条半径差 / 两条半径的均值 ≤0.30`，且均值 >0。

同样半径 8 和 12，得到 4/10＝40%，不通过。半径 9 和 11 则 2/10＝20%，通过。
所以不能把前一个“30%”理解为任意两条半径相差都不得超过 30%。

更细的实现差异：两两比较使用 `radius_px`；全局比较使用 `median_radius_px`。
全局 SEP 候选的前者也是像素中位半径；路线恢复候选的前者是**质心到中心的距离**。
后者对所有正式结构都是像素半径中位数。目前两者没有完全统一。

### 5.2 切向偏离角是什么

对正式结构的像素坐标计算整体形状长轴，再比较它与“中心到结构质心连线的垂线”的夹角。
取无方向长轴的最小偏离，范围 0°～90°：0° 最切向，90° 最径向。
它使用整个区域的形状，不是逐像素曲线拟合，因此整圈结构的整体长轴可能不可靠。

当前有三套不同门槛：

- 单条普通切向结构：偏离 **≤35°**。
- 整组切向性的一种入口：各有效偏离角的算术平均 **≤25°**。
- 整组切向性的另一入口：先按单条偏离 **≤30°**计数，通过比例 **≥0.67**。

最后一项分母是有有效偏离角的结构数，不是像素数。两个通过、三个可测时，2/3≈0.6667，
**严格小于 0.67**，不能当成自动满足。局部切向比例也存在同样的边界。

### 5.3 三种角度范围不能混用

| 名称 | 实際计算 | 用在哪里 |
| --- | --- | --- |
| 单结构角跨度 | 将该结构全部像素的绕心角排序，用 360°减去最大空缺角 | 普通弧 20°、稳健弧 30°、紧致结构 25° |
| 整组总角跨度（字段名叫总覆盖） | 合并全部正式结构像素，再用 360°减去最大空缺角 | 统一系统 60°、常规清晰系统 90° |
| 实际角向占据 | 72 个 5°小格中，有结构像素的小格数量×5° | 新增弯曲结构入口 90° |

前两项**不是连续亮弧的总长度**，会把跨度内部的空缺算进去。第三项也不保证连续，只说明哪些角格有像素。
折叠/尖点/紧致多像比较结构位置时，则使用结构质心的方位角，不是整条弧的全部像素角度。

### 5.4 核心半径和内连半径

- `near_core`（近核心）：候选 `radius_px ≤6.5` 像素。
- 候选“触及核心”：近核心，或像素中有任意一部分位于距中心 ≤6.5 像素。
- 内连结构：正式结构像素中有任意一部分距中心 **≤5 像素**，即默认搜索内半径 4 加 1。
- 评级的“非核心结构比例”按**结构条数**算，使用近核心标记，不是按非核心像素比例算。

### 5.5 独立模型存活比例

`逐结构存活比例 = 原结构像素中，在比较减除图里信噪比仍 ≥2 的像素数 / 原结构像素数`

两张减除图都用输入噪声图作分母。整组混合比例对正式结构掩膜的并集计算，因此大结构权重大，不是逐结构比例的简单平均。

| 数值门槛 | 真正用途 |
| --- | --- |
| **=0%** | 第一审计隔离；后端也有相关完全擦除判断 |
| **>0%** | 只表示没有完全擦除，可支持待复核候选的弱事实 |
| **≥50%** | 混合值可作为“信号可信”的一种依据 |
| **<50%** | 只有结合相关结构全部近核心，才形成后端的一种强伪影反证 |
| **≥75%** | 单弧及部分关系构型的逐结构强存活门槛 |
| **混合值<75%** | 追加模型敏感性提示，不直接决定等级 |

读旧观察记录时，逐结构存活优先读结构字段，其次读同结构的原子测量。只有确实仅 1 条正式结构时，
才允许用混合值回退；多结构场景缺逐结构值时不这样回填。比较模型本身失败时，逐结构值按不可用处理。

另外记录：

- **1 像素邻域存活比例**：对显著为正的比较图做 3×3 邻域扩张，再看原结构位置是否附近仍有信号。
  它不能用于补足 A 的 75%；但其等于零参与“彻底擦除”的强反证判断，所以并非完全不参与评级。
- **负残差比例**：原结构像素中比较信噪比 **≤−2** 的比例。目前记录而不设定级阈值。

代码：[正式结构与整组几何测量](../expert_agent/vision/pipeline.py)、[局部弯曲测量](../expert_agent/vision/curved_geometry.py)。

## 六、第二道前半：信号是否可信

令 N＝正式结构数。先要求数据可用、N≥1，再满足以下**任意一项**：

1. 比较模型成功，整组混合存活比例 **≥50%**；
2. “有持续性记录”的正式结构数 **≥max(1, floor(N/2))**。

其中“有持续性记录”只要求多阈值存活比例 **>0**，或 SEP 存活比例 **>0**。
这一步不是重新检查 3/8；完整跑图中，正式结构已经过第一道的 3/8 门槛。
`floor` 是向下取整：N＝5 时需要 2 条，不是严格过半的 3 条。

后端读取待复核候选的规则：

- 首先要求其审计结论是待复核，且有检测支持、有像素、综合信噪比 >0。
- **较强待复核依据**：再要求多阈值稳定、比较存活 >0、记录几何关系。
- **弱恢复依据**：要求恢复候选身份、比较存活 >0、记录几何关系；不要求多阈值稳定。
- 后一种可以在没有更高等级条件时支撑 C，不能直接支撑 B/A，也不生成 S 结构。
- 仅追溯记录没有由这条路径变成正式结构；前景污染候选比较存活为零，也不能冒充上述存活依据。

代码：[专家层信号判据](../expert_agent/agents/expert_assessment_agent.py)。

## 七、第二道主体：所有可能支持 A 的构型与阈值

### 7.1 公用结构类型

**普通切向结构：以下全部满足。**

- 切向偏离角 ≤35°；
- 整体长轴/短轴 ≥1.5；
- 单结构角跨度 ≥20°。

**新增弯曲结构：以下全部满足，也并入切向结构集合。**

- 实际角向占据 ≥90°；
- 径向相对宽度 `(半径第90百分位−第10百分位)/半径中位数 ≤0.5`；
- 至少 3 个有效局部形状扇区；
- 有效扇区中局部切向比例 ≥0.67；
- 不是近核心结构。

局部形状测量细则：分 12 个互不重叠的 30°扇区。每个扇区至少 5 像素、可测出非零长轴，
局部长短轴比 ≥1.5，且平均位置不在原点，才进入有效扇区分母。局部长轴偏离局部切线 ≤35°计为通过。
弯曲结构不必另满足整体长轴比 ≥1.5 或整体偏离 ≤35°。

**稳健弧结构：**已经属于切向结构，再全部满足：非核心、单结构角跨度 ≥30°、多阈值存活比例 >0。

**径向结构：**整体切向偏离角 ≥65°，且整体长短轴比 ≥1.5。没有额外的弧长门槛。

**紧致结构：**单结构角跨度 ≤25°。当前并没有另用点源大小或点扩散拟合来定义“紧致”。

### 7.2 六个“清晰构型”入口，任一个成立即可

除下表条件外，都需要第六节的信号可信。能否最终 A，还要过第八节的强替代解释判断。

| 入口 | 必须同时满足的条件 | 是否强制逐结构 ≥75% |
| --- | --- | --- |
| ① 常规统一构型 | 至少 2 条正式结构；全组半径变异系数 ≤30%；全组平均切向偏离 ≤25° **或** 偏离≤30°的有效结构占比≥0.67；全组角跨度≥90°；非核心结构条数占比≥50% | **不强制** |
| ② 单条稳健切向弧 | 至少 1 条“稳健弧结构”，且这条弧独立存活≥75% | 是，只检查可支持结论的那条弧 |
| ③ 折叠型弧对 | 两条切向结构；两两半径相对差≤30%；两结构质心方位最小夹角≤60°；两条分别独立存活≥75% | 是，两条都要 |
| ④ 尖点型三结构 | 三条切向结构；三质心的最小包络角跨度≤100°；每一对半径相对差≤30%；三条分别独立存活≥75% | 是，三条都要 |
| ⑤ 径向＋切向组合 | 存在径向结构，也存在切向结构；存在一个组合，其成员分别独立存活≥75% | 是；当前没有额外半径匹配/位置配对要求 |
| ⑥ 紧致多像 | 至少 4 条紧致结构；全组正式结构的半径变异系数≤30%；紧致结构质心包络角跨度≥180°；全部紧致结构分别独立存活≥75% | 是，全部紧致结构 |

补充边界，避免把代码想象得更完整：

- ①使用全部正式结构的整组量，不自动枚举最优子集。非核心≥50%也是按全部正式结构数计算。
- ③④不额外要求非核心，也不另设“3/8”检查；正式结构身份及信号可信已经是前置条件。
- ⑤目前没有显式要求径向成员和切向成员 ID 不同。新增弯曲入口使一条结构理论上可能同时进两集合；
  这是当前实现边界，不能描述成已完成严格不同像的配对验证。
- ⑥全组半径一致性不是只用紧致子集；独立存活则检查全部紧致结构，不是任选 4 条最好的。
- 紧致双像可以在报告里显示“可能”，但当前紧致多像 A 入口要求至少 4 条，不能声称已覆盖所有双像。

### 7.3 60°到底在哪用

“初步统一系统”条件是：至少 2 条结构、全组半径相近、整组切向条件成立、全组角跨度 **≥60°**。
它是 B 的一个入口，也是常规清晰系统的前置条件；不能单凭 60°直接 A。
折叠弧对的 **≤60°** 则是两条结构质心方位不要离得太远，方向和含义都不同。

### 7.4 旧环候选兼容分支

旧观察记录如有环候选：最长高于局部背景的连续跨度 **≥180°**，环上减环外信噪比 **>0**，
且正式结构至少 2 条，则代码记为相干环。
常规清晰入口可以用它替代“整组跨度≥90°”，但仍需初步统一系统，即≥60°等条件，以及非核心≥50%。

**当前完整视觉链不再生成旧环候选列表，该列表为空。** 上述分支用于旧/外部观察记录，不能当作当前正在额外检测的环。

### 7.5 报告里说构型“支持”，是否已经够 A？

不一定。报告的“折叠支持”“尖点支持”“切向弧支持”部分标记可以只反映几何关系满足，
而实际进入清晰构型还要求信号可信和对应的逐结构 75%。
弯曲结构让“环/部分环”标记为支持，也不单独绕过六个清晰入口。
“不对称多像”当前只保留可能性，不是独立的第七个 A 入口；孤立、无辨识性单像也不是。

代码：[专家层构型与清晰系统条件](../expert_agent/agents/expert_assessment_agent.py)。

## 八、第二道后半：哪些反证会挡住 A？

`有同等强的替代解释 = 强伪影反证 或 强普通星系形态反证 或 有多核代理`

### 8.1 强伪影反证

先确定“相关结构集合”，按下列优先级取第一个非空集合：

1. 全部稳健弧结构；否则
2. 全部切向结构；否则
3. 全部正式结构。

以下任意一项成立，就记强伪影反证：

- 相关集合非空，**每条**相关结构的逐结构独立存活 **<50%**，并且**每条**都被标为近核心。
- 相关集合非空，**每条**相关结构的原位置存活比例 **=0**，并且其 1 像素邻域存活比例也 **=0**。
- 主前景模型失败，并且相关结构中找不到任何一条独立存活 **≥75%**的结构。

因此“混合比例<50%”本身不再是一条强反证，但“主模型失败又缺乏局部独立强支持”仍可能挡 A。
报告写“模型失败不是固定降级”并不意味着代码完全忽略它。

### 8.2 普通星系自身结构反证

先定义代理指标：

- **内连结构数**：有像素进入中心≤5像素范围的正式结构条数。
- **不对称程度**：取围绕中心、可做180°旋转对比的最大对称矩形残差图，
  `原图与旋转图之差的绝对值总和 / (原图绝对值总和 + 旋转图绝对值总和)`。
  分母为零时记0；不能形成足够对称窗口时为未知。
- **核心残差比例**：中心≤6.5像素内残差绝对值总和 / 中心≤25像素内残差绝对值总和；分母零时记0。

“普通星系形态解释可行”：内连结构数 **>0**，或不对称程度 **≥0.65**。
但要达到**足以挡 A 的强解释**，必须三项同时成立：

1. 内连结构数 **≥2**；
2. 不对称程度 **≥0.65**；
3. 核心残差比例 **≥0.50**。

只碰到内圈、只不对称，都不等于自动否决 A。

### 8.3 多核/相互作用代理

从最初的前景 SEP 对象中，除主对象外，其他对象若同时满足：

- 质心到选定中心距离 **≤6.5 像素**；
- 绝对通量 **≥主对象绝对通量的10%**；

就计作一个次核代理。**只要次核数>0，当前代码就把它并入“同等强替代解释”。**
这里不是“多核提示而完全不影响评级”，也没有要求额外光谱、颜色或质量模型确认它真是另一个核。

### 8.4 噪声/坏像素解释

坏像素比例 **>0**，或信号不可信，会让噪声/坏像素解释显示为可行。
但坏像素比例>0本身**没有直接并入上述强替代解释总开关**。
数据可用性仍按第二节单独约束；两者不要混为一条规则。

代码：[代理量计算](../expert_agent/vision/preprocess.py)、[强替代解释](../expert_agent/agents/expert_assessment_agent.py)。

## 九、最终 A/B/C/X：完整优先级

代码不是先给各项分数加权，也不先算0～3连续分。按照下表自上而下，**命中第一项就结束选择**。

| 优先级 | 条件 | 输出 |
| --- | --- | --- |
| 1 | 数据不可用 | 信息不足、弃权，不是 X |
| 2 | 六个清晰构型入口至少一个成立，且没有同等强替代解释 | A |
| 3 | 有清晰构型，但有同等强替代解释 | B |
| 4 | 信号可信；且有初步统一系统、切向结构、径向＋切向组合三者之一；且没有同等强替代解释 | B |
| 5 | 有较强待复核依据，或有数据可用的弱恢复依据 | C |
| 6 | 有正式结构，并有切向或径向结构 | C |
| 7 | 有正式结构，且信号可信 | C |
| 8 | 以上均不满足 | X |

由此可见：

- “有强反证”不等于一律 X。清晰构型仍在时，当前结果是 B。
- “正式结构为0”也不必然 X；可测且满足条件的待复核候选可保留 C。
- 单独径向结构没有单独 B 入口；仍可能落在 C。
- 没有“全部通过75%就A”，也没有“半径不一致就必定不是A”，因为六个入口条件不同。
- `vote_category` 是选出的类别；兼容等级与其相同。数字编码、专家锚点、连续分与分数区间均置空。
- A+科学价值标记当前初始化为空，没有本地规则自动授予 A+。

## 十、第三道：判决审计到底检查什么

这层**不再量半径、角度、75%**，也不是第二位天文专家。它检查产生的证据与结论记录。
只要下述问题列表任一项非空，就标记审计不通过。

| 检查 | 当前实际执行方法 |
| --- | --- |
| 引用不存在 | 检查事实所引测量ID、对象ID、观察记录顶层字段；对部分实体引用再查ID |
| 把未知当反证 | 检查反证文本是否包含缺失信息主题字符串；这是文字规则，不是语义推理 |
| 重复决定性证据 | 决定性证据列表出现重复ID就报错 |
| 相关证据重复相加 | 同一相关组被多次用作决定性证据，且理由英文含 `add`（相加）才触发这部分检查 |
| 只有测量没有透镜关系却判高等级 | B/A 的决定性证据必须至少有一项与“透镜特异关系证据引用”相交 |
| 自动惩罚恢复来源 | 恢复候选风险项只能标为增加不确定性；若被写成其他作用就报错 |
| 漏掉竞争解释 | 必须列出：透镜、普通星系形态、并合/相互作用、前景减除/点扩散伪影、噪声/坏像素/投影源五类 |
| 外部答案泄漏 | 在理由、已观察事实及其引用中扫描预设字符串，见下文 |
| 类别与旧字段矛盾 | 检查类别与兼容等级相同、数字编码与旧锚点相同；旧锚点若非空则核对X/C/B/A对应关系 |
| 区间被强行写成单点等级 | 分数区间和等级同时非空时报错 |
| 应当弃权却给等级 | 数据标记不可用或中心有歧义时，类别必须为信息不足 |

答案泄漏扫描词为 `official_expert_score`（官方专家分）、`official_grade`（官方等级）、
`zenodo_label`（资料库标签）、`known_lens`（已知透镜）、`pyautolens`（外部建模软件名）、
`source_reconstruction`（源重建）。这是有限字符串检查，不是完整信息泄漏防护证明。

实现边界：

- 顶层引用存在，不等于所有嵌套字段/数值都被逐个验证；目前引用检查不是完整语义验证器。
- 它不重新执行第二道全部几何门槛，也不独立确认图上的弧是真实天体。
- 判决审计自己的弃权检查不重复99%和噪声数值公式，主要依赖可用标记和中心标记；专家层检查更细。
- 审计不通过只留下 `required_corrections`（要求修正的问题）；当前工作流不自动执行这些修正。
- 报告中的“去掉关键证据后结论是否保持”不是实际逐次删证据重跑，只根据决定性证据数量等写标记。

代码：[判决审计](../expert_agent/agents/decision_audit.py)、[报告写出](../expert_agent/agents/report_writer.py)。

## 十一、哪些数值只是描述，哪些旧规则已停用

### 11.1 不是评分，也不是额外硬门槛

测量可靠性仍有0～1数值，但不求和成专家分，也没有“可靠性低于20%直接把对象判X”的总门槛。
当前专家给结构事实贴可靠性标签时，取已知测量可靠性最小值：

- 最小值≥0.75：高；
- 否则最小值≥0.20：中；
- 否则低。

这个标签并没有直接加入第九节类别选择条件。部分可靠性来源例子：

| 测量 | 可靠性记录方式 |
| --- | --- |
| 正式结构综合信噪比 | min(0.7, abs(综合信噪比)/20) |
| 正式结构形状 | 将(轴比−1)/1.5截到[0,0.7] |
| 正式结构半径/角跨度 | 分别固定0.65/0.6 |
| 多阈值/SEP存活测量 | 存活比例本身；缺失SEP时为0 |
| 逐结构比较/弯曲测量 | 通常0.55；比较缺失时为0 |
| 邻域存活/负残差比例 | 0.5 |
| 前景可靠性 | abs(前景通量)/(20×背景噪声)，截到[0.25,1]；中心歧义时上限0.25 |

此外，颜色一致性、反像专门搜索、红移、质量模型和同源重建没有成为当前已执行的数值定级条件。
缺失信息按未知记录，而不是假装测到了“不一致”。点扩散信息确实可用于独立比较模型，但没有另一套“点扩散匹配分”加进等级。

### 11.2 仍在目录中，但不能混进当前活动规则

- 配置里的 `evidence_low_specificity_threshold=0.35` 由旧证据审计器使用，不是当前活动判决审计的35%门槛。
- `center_search_half_size=40` 是保留的旧配置，不再驱动当前最亮中央窗口选中心。
- 旧多假设/证据/评分准备代理文件仍在，但当前专家工作流没有调用它们。
- 旧环候选180°规则仅为旧记录兼容，当前完整视觉链不产生该列表。
- 旧“混合存活<50%本身就构成强伪影解释”的逻辑已被移除；但混合≥50%的信号可信入口仍存在。
- `path_support_relations`（整组件路线支持函数）仍在文件中；当前交接使用局部像素分割，不能把未调用函数的条件混列为现行交接门槛。
- 没有 B-A 这种最终等级；没有通过0/1/2/3聚合出连续分再分箱的运行步骤。

### 11.3 PNG 输入的明确差异

| 项目 | PNG 实际设置 |
| --- | --- |
| 初次源检测 | 至少2.5倍噪声 |
| 信噪比阈值 | 3、4、6，共3层 |
| 稳定性 | 至少2/3层 |
| SEP参数 | 仅16层分裂、0.01对比这一组 |
| SEP稳定次数 | 至少1次 |
| 残差SEP检测 | 至少3倍噪声 |
| 结构像素保留及比较存活 | 信噪比至少3，而非FITS的2 |
| 前景主模型 | 直接采用径向模型，记录为成功的PNG简化模式 |
| 噪声与点扩散 | 从灰度显示图估计统一噪声，没有FITS同等级标定，也无输入点扩散图 |

几何阈值仍沿用，但强独立模型比较入口可能因点扩散信息缺失无法满足；不能把 PNG 和 FITS 的结果当成同精度。

## 十二、附录：影响审计量的模型数值设置

这些是模型生成参数，不是 A/B/C 等级门槛；列出是为了不把背后的数值条件藏起来。

### 12.1 主前景模型

- 椭圆等亮度线起始半长轴5像素；最大半长轴 min(60像素, 图像短边×0.45)。
- 初始椭率截到0.05～0.7；3倍散布裁剪、2次裁剪迭代。
- 有限且强度>0的有效等亮度线至少5条，否则走失败回退。
- 亮度平滑优先窗口7，椭率/方向优先窗口5；短序列自动缩短或跳过，二阶平滑。
- 回退径向模型使用1像素宽环带中位数；有至少2个有效半径点时插值，否则用全局中位数。
- 背景残差噪声优先从距中心>37.5像素且未屏蔽区域测量；没有该区域则用未屏蔽区域。

### 12.2 独立比较模型

- 需要可用点扩散图；归一化总和绝对值必须>10⁻¹²，否则模型不可用。
- 使用固定几何的10个高斯分量，宽度为0.7/1.1/1.7/2.6/4.0/6.2/9.5/14.5/22.0/34.0像素。
- 椭圆短长轴比限制在0.25～1；拟合半径≤min(50像素, 图像短边×0.45)。
- 初始有效、未屏蔽拟合像素至少80个；高斯系数非负，常数背景不限制正负。
- 最多3轮稳健拟合；每轮求解最多300次迭代，求解器必须报告成功。
- 每轮仅保留偏离残差中位数≤3.5倍稳健散布的拟合像素；散布≤0或掩膜不再变化则结束。
- 最终系数必须有限，异常或未收敛则比较失败。

这里“独立”指另一种光模型实现，不代表具有完全独立的数据。求解成功也不等于物理模型已获验证。
残差相关系数需要搜索环带中至少3个有限像素才计算；目前相关系数本身没有评级阈值。

代码：[模型实现](../expert_agent/vision/foreground_models.py)、[前景实现](../expert_agent/vision/preprocess.py)。

## 十三、最简总括

**正式交接**主要看：数据可用、检测事实、正信号、3/8多阈值稳定性、有没有被比较模型完全擦除。

**评级**主要看：信号可信、六种清晰构型入口、三类强替代解释，再按优先级选一个字母。

**最后审计**看：证据引用与结论记录是否犯错，不重新认图，不自动回退重跑。

最值得逐项复核的现状是：99%的严格边界、两种不同半径公式、跨度不等于实际连续覆盖、30°/35°不同切向口径、
0.67不等于精确2/3、并非所有A都要求75%、多核代理确实会挡A、待复核不等于正式结构、审计失败目前不自动纠正。
