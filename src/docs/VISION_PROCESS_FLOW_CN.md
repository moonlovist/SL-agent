# LensAgent 视觉处理流程

这份文档是项目唯一的固定视觉流程说明。流程架构不会随样本变化，因此不再向每个对象的输出目录重复写入同一张流程图。

```mermaid
flowchart LR
    A["FITS / PNG 输入"] --> B["读取图像、噪声与中心定位"]
    B --> C["污染源掩膜与前景星系建模"]
    C --> D["前景星系减除残差与残差 S/N"]
    D --> E["S/N 多阈值稳定性检测"]
    D --> F["SEP 多参数共识检测"]
    E --> G["弧候选像素交集"]
    F --> G
    G --> H["几何、形态和信噪比测量"]
    H --> I["Observation 结构化观察事实"]
    I --> J["多假设推理、审计与报告"]
    D --> K["NPZ 数值证据"]
    E --> L["PNG 样本过程图"]
    F --> L
    G --> L
    K --> M["Manifest 参数与文件清单"]
    L --> M
```

## 边界

- 视觉层负责记录“看到了什么、测量到什么”；
- 视觉层不直接输出透镜或非透镜结论；
- 每次样本运行只保存该样本实际产生的诊断图和过程图；
- 固定架构流程只在本文档维护一份。
