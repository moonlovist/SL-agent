## 这次实际改了什么

- 当时新增可选 `--candidate-handoff-review` 模式并默认关闭；该开关现已删除，完整交接已成为默认流程。
- 为 model-chain 的所有已有候选保留完整的像素域测量，包括正式结构、弱阈值候选、旧前景隔离候选及路线外 SEP 候选。
- 新测量包括真实掩膜的像素数、质心、半径、角跨度、二阶形态、局部曲率相关几何量、孔径信号、比较残差孔径通量及阈值占比。
- 新增 `candidate_handoff_review` 观测档案、`candidate_review_facts` 证据条目及 `candidate_configuration_review` 路线复核分组。推理层只读取观察档案，不访问像素。
- 比较图上没有像素达到阈值时，记为 `below_threshold`，不据此判定物理污染、整段弧消失、本征结构或非透镜。历史审计标签仅保留为基线对照。
- 缺少掩膜、尺寸/像素数/中心不一致、无效RMS等情况明确记为不可测量，不伪造测量。没有比较模型时记为不可用，不当负面证据。
- 新增候选对照图与中文报告；正式评分继续使用原结构列表，新待复核区域不影响整体几何统计、不自动升级，也不能作为决定性正负证据。

这里的“完整”是指补齐**已有检出掩膜的像素测量**，不是已经找全真实弧，也不是补画缺失像素。3316 中低于原检测阈值而没有检出的区域仍需另行验证检测方法；本次没有改检测器或平滑原图。天空坐标未在回放时重算，仍报告像素域几何。

## “前景比较存活率”到底是什么

当前数值实际表示：同一个候选掩膜内，在另一种前景模型扣除的残差图上，达到指定像素SNR阈值的像素比例。

它不是通量保留率，不是“有多大概率真实”，也不是来自第二次独立观测。
比例为零与孔径内仍有正通量可以同时成立；前景模型变化、噪声、过扣除、真实信号都可能影响该数值。
所以新档案保留比例和比较孔径通量，物理来源仍标记为未决。

名义孔径 SNR 使用 `sum(residual) / sqrt(sum(input_rms**2))`，未计入像素协方差、前景拟合不确定性和搜索选择效应，不是已校准的显著性或真实概率。
几何路线、阈值存活和形态来自同一幅残差，不重复算独立证据；同一候选关联多条路线，也不是多票支持。

## 尚未更改的部分

本次只完成候选测量交接与复核层，没有将待复核候选接入正式分级。
默认审计门控、0.75 比较阈值、共同半径离散阈值、检测器以及 A/B/C/X 映射均保持原样。
因此这是有意隔离评分影响的第一阶段，不应把“等级不变”解释成新评分方案已经科学验证。
候选来源真实与否、是否支持透镜、支持哪个等级仍需独立论证。

## 使用方式与后续确认

从项目目录运行，务必使用新的输出目录：

```powershell
python -m expert_agent.cli analyze "候选文件.fits" --output "新试验输出目录" --candidate-handoff-review
```

不加此开关即原默认流程。新档案保存后，可直接用现有 `reason observation.json` 复核，不重复读取图像。

用户确认前不切换默认评分规则、不覆盖旧评级结果。
要把候选复核证据接入正式分级，下一阶段需预先固定评价准则，并加入非透镜负例、低信噪比/不同弧形的注入回收、独立留出测试集及等级迁移清单；仅有 A 样本不能测量误报率。不能以“这些 A 样本全部升 A”为修改成功标准。

后续进展：2026-09-05 曾实现可选修订评级；2026-09-06 已合并为唯一默认评级。详见 [候选证据评级历史记录](<G:/Astronomy/LensAgent - 副本/src/docs/CANDIDATE_INCLUSIVE_GRADING_TRIAL_CN.md>)。
