# v0.23.0 前景中心与前景光建模修订

状态：开发者验证中的试验流程，不是经标定的 Euclid 透镜分类器。

## 问题诊断

三组失败样例中的核区交替正/负同心环，与不含 PSF 卷积的等亮度线模型失配一致。原流程还把最亮整数像素当作模型中心，而不是亚像素光度质心，会在 PSF 尺度上加重偶极型残差。

`102020528_NEG557594873487530963` 的旧规则只选离切图中心最近的 SEP 对象，因而把约 `(150,146)` 作为中心，虽然它已记录约 `(180,128)` 处存在流量约 3.2 倍、尺寸也更大且光分布重叠的扩展源。警告没有改变后续单中心拟合，因此实际上仍在用已知歧义中心。

## 实现改动

1. 有有效 PSF 时，按输入 RMS 加权、迭代稳健剔除的 PSF 卷积固定几何 MGE 成为主前景光模型。无 PSF 或 MGE 失败时仍回退到原等亮度线/径向模型。
2. MGE 使用 SEP 保存的浮点质心建模；整数峰值仅供数组索引和显示。
3. 原等亮度线模型不丢弃，改为同一曝光上的敏感性对照。两种残差的一致性不得被称为“独立证据”。
4. 无显式目标坐标时，若存在“更大、更亮、与中心源的扩展光分布重叠”的竞争对象，流程保留多中心假设并标记歧义，**不依据亮度自动切换，也不继续自动评级**。远处亮星/星系同样不能仅因为亮而抢占中心；可信目录或用户提供的显式坐标始终优先。
5. 中心审计保留所有位置候选、竞争扩展源及“无红移时不能确认前景身份”的限制。已有外部身份信息时，可用 `--center-x/--center-y` 明确选择要检验的中心假设。
6. 多波段颜色不再只是展示项。VIS继续负责原分辨率形态；VIS、Y、J、H按文件MAGZERO校准，并以不做反卷积的高斯二阶矩近似匹配到最宽PSF。候选颜色使用受保护的固定椭圆径向前景扣除，旋转控制孔径用于增大局部误差。
7. 两个拟议像的颜色允许任意无色差亮度倍率后再比较；不要求星等相同。可靠颜色不一致，或所有可靠候选均无法和前景颜色区分，会把清晰形态的A限制为B。颜色一致只能支持已经存在的透镜构型，不能单独创造A；不要求弧必须蓝。
8. 共同PSF孔径重叠超过20%、候选颜色孔径与前景核心重叠超过15%、少于3个可靠共同波段或低信噪比时，该关系记为unknown，不参与降级。

## 天文学依据与边界

MGE 是标准的星系表面亮度参数化方法，高斯分量便于包含 PSF 卷积：[Cappellari 2002](https://academic.oup.com/mnras/article/333/2/400/1019346)。针对强透镜的新工作也将 MGE 用于前景透镜光，并与背景源像素重建联合拟合：[He et al. 2024](https://academic.oup.com/mnras/article/532/2/2441/7700720)。成熟的强透镜建模通常同时拟合前景光、质量与背景源，并在与数据比较前卷积 PSF：[AutoLens](https://academic.oup.com/mnras/article/478/4/4738/5001434)。

本版只完成“稳健前景光 MGE”，**没有**实现同时的透镜质量与背景源重建。因而它可以减少 PSF/核区模型失配，但仍可能把部分被透镜光吸收进前景模型。这也是保留等亮度线对照和全部候选追踪信息的原因。

颜色一致是强透镜专家判断的重要关系证据：同一背景源的多个像在理想情况下具有相同SED形状，只相差放大率；候选与前景颜色差异也有助于分离不同红移成分。但颜色不是绝对判据：透镜星系污染、尘埃消光、时延叠加源变、微透镜和PSF失配都可能制造色差，红色背景源也可能与前景颜色接近。因此本版只让可靠颜色关系调节A/B置信度，不用单一颜色否决透镜或把B/C直接升A。

光学图像中的亮度、尺寸和位置不能单独证明前景/背景身份。若有可信的目录坐标或红移，应通过 `--center-x/--center-y` 或后续的多分量联合建模明确传入，不应让图像启发式替代物理身份。
