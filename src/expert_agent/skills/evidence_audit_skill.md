# Evidence Audit Skill

## Purpose
Test whether evidence is traceable, independent enough, and interpreted in proportion to its specificity.

## Procedure
1. Validate evidence IDs and measurement references.
2. Ensure unavailable evidence is neutral.
3. Identify repeated effects and shared correlation groups.
4. Flag low-specificity facts that are common to several hypotheses.
5. Require each observed fact to be compared across all active hypotheses.

## Guardrail
Several measurements derived from the same pixels are correlated evidence, not several independent discoveries.
