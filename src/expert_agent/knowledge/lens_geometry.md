# Lens Geometry Knowledge

- A plausible lens configuration has a measurable central mass/light centre and one or more structures arranged around it.
- Tangential alignment, comparable radii, and angular coverage are more discriminating together than any one quantity alone.
- A single curved feature is compatible with lensing but is not sufficient: intrinsic arms, rings, interactions, and subtraction residuals remain alternatives.
- Geometry derived from the same residual pixels is correlated and must be aggregated once.
- Missing redshift or mass-model agreement limits confirmation; the visual agent should report a candidate, not a physically confirmed lens.
